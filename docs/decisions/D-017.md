# D-017: Stage Collision — 2D Polylines, vertex2 Is Count

Category: Asset Pipeline

## Decision
- `MPVertexLinks { u16 vertex1, vertex2 }`: `vertex2` is a count, not a second index
- Lines are polylines: `for (v = vertex1; v < vertex1 + vertex2 - 1; v++)`
- Array lengths derive from data (max `group_id + line_count`, etc.)

## Why
- Dream Land line 3 = `{9, 2}`: vertices 9..11, symmetric platform at y=0
- "Second index" reading gives wrong geometry
