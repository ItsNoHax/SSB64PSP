# D-002: Preconversion Over Runtime Conversion

Category: Rendering Architecture

## Decision

- Textures, meshes, animations: converted at build time
- Pack ships PSP-native formats

## Why

- PSP CPU and bandwidth: the bottleneck
- N64 32-entry vertex cache forces re-uploads; build-time indexing gives 2.09x reuse
- Build-time material merging: fewer GE state changes
- Positions and most UVs: compact 16-bit GE fields

## Consequences

- N64 S10.5 UVs signed; `GU_TEXTURE_16BIT` unsigned
  - primitives with negative coordinates on clamped axes: marked at pack time
  - marked primitives: float UVs at draw time
- Common indexed path: 20 bytes per vertex, not 36 (RE-262)

- `crates/ssb-rom/src/texture.rs`, `psp_texture.rs`, `mesh.rs`, `pack.rs`
