# D-006: Vertex Format — 16-bit Normalized Requires Model Scale

Category: Rendering Architecture

## Decision

- `GU_VERTEX_16BIT`: coordinates read as normalized fixed point (divide by 32768)
- Undo: uniform model-matrix scale of 32768
- UVs: S10.5 (32 units/texel); `sceGuTexScale(1024/w, 1024/h)`

## Why

- Unscaled: N64 coordinates in the hundreds become hundredths (invisible speck at origin)
- Precision unaffected: coordinates are integers well inside `i16`

## Implemented

- `psp-runtime/src/meshdraw.rs::MODEL_SCALE`
- `sceGuTexScale(1024/width, 1024/height)`
