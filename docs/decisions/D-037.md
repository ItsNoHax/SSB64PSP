# D-037: Reference Ports Are Technical References, Not Authorities

Category: Engineering Process

## Decision
- Ports: `BattleShip`, `sf64-psp`, `n64psp`, `oot-PSP` (`https://github.com/z2442/oot-PSP`)
- Consult for technique only
- No wholesale copy of architecture or assumptions
- Never authoritative over SSB64 decomp or ROM
  - disagreement: investigate, prefer decomp/ROM (`AGENTS.md` "Reference order")
- Port feature this renderer lacks: classify as
  1. SSB64 needs it
  2. SSB64 does not use it
  3. PSP needs a different implementation
  4. project incomplete
- Record conclusion in an evidence record (RE-124 is the first audit)
- Never copy Nintendo assets or copyrighted data from them

## Why
- oot-PSP shares the PSP platform; OoT rendering needs differ from SSB64
- Non-authority rule applies to every reference port
