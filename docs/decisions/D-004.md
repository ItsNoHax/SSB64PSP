# D-004: Coordinate Systems — No Handedness Flip, No Matrix Transpose

Category: Rendering Architecture

## Decision

- N64 and PSP: both right-handed, +Y up, view down -Z
- N64 row-major/row-vector cancels PSP column-major/column-vector
- Real work: s15.16 to `f32` widening only

## Why

- Transposes cancel: `Mpsp[i][j] = M64[j][i]`
- Test `row_vector_translation_lands_in_the_translation_column`: caught an early transpose bug
- `ftPhysicsApplyGravityClampTVel`: `vel_air.y -= gravity`, confirms +Y up

## Implemented

- `crates/ssb-engine/src/coord.rs::n64_to_psp_matrix`, `n64_to_psp_position`
