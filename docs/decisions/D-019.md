# D-019: Collision Query — Swept Segment, Not Point Test

Category: Gameplay Model

## Decision
- `mpCollisionCheckFloorLineCollisionSame` tests swept segment, old to new position
- Dispatch on flat vs tilted segment
- Landing snap tolerance: 0.001

## Why
- Stops fast fallers crossing a platform in one frame
- 0.001 is a decomp literal, not a tuning knob
- Lets a fighter standing exactly on a surface register as touching
