# D-020: Animation — Figatree (AObjEvent16) for Fighters, AObjEvent32 for Stages

Category: Asset Pipeline

## Decision
- Fighters: compact 16-bit `AObjEvent16` (figatree)
- Stages: 32-bit `AObjEvent32`
- Both share `AObj` interpolation (cubic/linear/step)
- Pack both

## Why
- Decomp uses both formats
- Figatree: per-joint command stream with `ftAnimGetTargetValue` scales
- Stage animation validated three ways
  - ROM replay
  - pack pose match (444,960 values)
  - device frame diff

## Implemented
- `crates/ssb-rom/src/figatree.rs`, `anim.rs`, `objanim.rs`, `anim_table.rs`
