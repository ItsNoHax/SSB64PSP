# D-028: Asset Pack Mandatory — Built Separately by romtool

Category: Asset Pipeline

## Decision
- `cargo psp`: builds executable only
- `romtool pack`: builds `assets/generated/ssb64.pak`
- `run-ppsspp.sh`: stages both

## Why
- Clean separation
- Without a pack, viewer falls back to built-in tetrahedron
