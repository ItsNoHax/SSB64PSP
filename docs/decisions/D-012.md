# D-012: DObjDesc Arrays — Depth-Tagged Flattened Tree

Category: Asset Pipeline

## Decision
- `DObjDesc.id & 0xFFF`: node depth
- Parent: most recent node at `depth - 1`
- Terminator: depth 18 (out of range)
- High nibble: matrix composition kind

## Why
- Recovered by 5-constraint scanner
- Validated: 363 arrays, 134 files
- Per-file counts identical to decomp; 180 annotated arrays exact

- `crates/ssb-rom/src/scan.rs`, `scene.rs`
