# D-001: No RDP Emulation — Build-Time Display List Conversion

Category: Rendering Architecture

## Decision

- F3DEX2 display lists: parsed at build time
- Lowered to PSP vertex buffers + `sceGu` state
- RDP never emulated at runtime

## Why

- SSB64 geometry: static ROM data (Star Fox 64 DLs are dynamic)
- Preconversion: cheaper on the 333 MHz CPU
- `sf64-psp` translates at runtime because it must

## Implemented

- `crates/ssb-rom/src/dl.rs`, `mesh.rs`, `pack.rs`
