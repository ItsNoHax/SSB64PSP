# D-005: Fixed 60 Hz Simulation Decoupled from Rendering

Category: Rendering Architecture

## Decision

- Simulation: fixed 60 Hz tick
- Rendering: follows PSP display cadence (~59.94 Hz)
- Accumulator with capped catch-up

## Why

- Every decomp timing constant: in frames
- `scheduler.c`: `osViSetEvent(..., INTR_VRETRACE, 1)`, one event per NTSC retrace
- Steady state: one tick per vblank
