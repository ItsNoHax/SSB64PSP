# D-027: no_std Discipline — Workspace Default-Features = false

Category: Platform & Toolchain

## Decision
- `ssb-rom`, `ssb-engine`, `ssb-game`: `no_std`, `default = ["std"]`
- Workspace dependencies: `default-features = false`
- Crates wanting `std`: opt in via own `std` feature
- CI builds all three for `thumbv7em-none-eabi` to catch leakage

## Why
- Crate cannot turn off a workspace dependency's default features
- Leaked `std` fails PSP build with confusing "can't find crate for `std`"

## Implemented
- root `Cargo.toml:31-33`
- each crate's `Cargo.toml`
