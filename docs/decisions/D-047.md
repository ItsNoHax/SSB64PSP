# D-047: CRT Overscan Crop — the N64's Visible Box Fills the PSP's Height

Category: Rendering Architecture

Supersedes: [D-008](D-008.md).

## Decision
- Map N64 320×240 frame so inset box (10, 10)–(310, 230) fills PSP's 272 lines.
  - Box is the part a CRT showed.
- One scale on both axes: 272/220 ≈ 1.236.
- N64 (160, 120) → PSP (240, 136).
- Box spans PSP x 54.5–425.5 (~371 columns, N64's 15:11).
- Visible pixels: centres inside box, (55, 0)–(425, 272); black pillarbars either side.
- 10-pixel strip around the box: cropped. Nothing stretched.
- `ssb_engine::coord`: the only N64→PSP screen mapping.
  - `n64_to_psp_x`/`_y`, `n64_rect_to_psp(_xywh)`.
  - `n64_scissor`: pixels whose centres a rectangle holds, clipped to visible area.
  - `visible_area`, `psp_pixel_edge`.
  - `n64_pixel_to_psp_column`/`_row`: where a framebuffer copy samples an N64 pixel.
- Viewport entry points:

| Function | Use |
|---|---|
| `Gpu::set_viewport_n64` | camera's N64 viewport, scissored to visible area |
| `set_viewport_pillarboxed` | whole 320×240 frame as viewport, scissored to visible area; 2D, full-frame content |
| `set_viewport_fullscreen` | port's own diagnostics in PSP pixels only |

- `set_viewport_n64`: scale and centre sent as floats; `sceGuViewport` halves an integer width.
- `begin_frame`: clears whole screen, restores last chosen viewport and scissor.
- Everything goes through the mapping:
  - Sprites, fills, depth mask, screen and 3D particles.
  - Wallpaper, pause border, screen flash, frozen picture.
  - Transition and wallpaper photo copies, staff roll's halved 640×480 screen.
  - No-pack diagnostic slots.
- Battle camera frames by `gGMCameraStruct.viewport_width / viewport_height` (300 / 220).

## What the strip held
- N64 never draws there.
  - libgc clamps every camera scissor 10 pixels inside frame: `dGCCameraScissor*` = 10, `gcSetCameraScissor` never called.
  - N64 captures of opening, title, menus: black outside box (RE-477).
- N64 itself clips sprites partly outside:
  - Fighter tag or item arrow at top edge, countdown zoom, menu slide-ins.
  - How to Play window's last 4 rows.
- Crop removes the port's old difference.

## Why
- User decision.
- Under D-008 the strip showed as a border where wallpaper or menu background appeared but stage did not.
- Crop shows the picture as a CRT did, 9% larger.
  - Battle viewport covers 100,640 pixels instead of 84,411.

Status: Adopted (RE-477).
