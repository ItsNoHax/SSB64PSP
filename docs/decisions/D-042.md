# D-042: A Reopened Render State Stays Provisional Until It Is Measured

Category: Rendering Fidelity

## Decision
- Source-derived implementations and regression captures stay valid evidence for the paths they cover.
- Render-state claim reopened by new evidence is provisional until a measurement against the original closes it.
  - Scope: texgen, lighting, depth, submission order, GE cache.
- One depth bit is not the N64 depth model: compare and write are separate state.
- Lighting and matrix provenance: carried from load time, never inferred at draw time.

## Why
- 2026-09-10 reconciliation found correctness gaps, not performance work:
  - `CacheEntry` lacked load-time lighting and matrix provenance.
  - `merge_by_material` grouped globally.
  - `MeshMaterial` held one depth bit.
  - Raw GU paths bypassed the cache-controlled material path.

## Result
- RE-225–RE-239: corrected texgen semantics.
- RE-240–RE-261: closed PRIM ownership, lighting provenance, independent depth state, submission order, GU cache isolation; integrated regression passed.
- Open follow-up: 164 cross-node differing-transform vertex reuses (RE-225), quantified.
- Primitive-level texgen ([D-039](D-039.md)) unaffected.
