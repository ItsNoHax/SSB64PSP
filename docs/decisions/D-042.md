# D-042: A Reopened Render State Stays Provisional Until It Is Measured

Category: Rendering Fidelity

**Decision:** Source-derived renderer implementations and regression captures
remain usable evidence for the paths they cover, but a render-state claim
reopened by new evidence (a texgen, lighting, depth, submission-order or GE
cache question) is provisional until a measurement against the original
closes it. In particular, a single depth bit is not the N64 depth model
(compare and write state are separate), and lighting and matrix provenance
must be carried from load time, not inferred at draw time.

**Reasoning:** The 2026-09-10 reconciliation found concrete gaps between the
implementation and stronger completion claims: `CacheEntry` did not retain
load-time lighting or matrix provenance, `merge_by_material` grouped
globally, `MeshMaterial` had one depth bit, and raw GU paths bypassed the
cache-controlled material path. These were correctness questions, not
performance work.

**Result:** RE-225–RE-239 measured and corrected texgen semantics;
RE-240–RE-261 closed PRIM ownership, lighting provenance, independent depth
state, submission order and GU cache isolation, then passed the integrated
regression. T1's 164 cross-node differing-transform vertex reuses (RE-225)
remain a quantified follow-up, not an unmeasured claim. Primitive-level
texgen ([D-039](D-039.md)) is unaffected.

**Reference:** RE-217, RE-225, RE-261, `AGENTS.md` "Constraints"
