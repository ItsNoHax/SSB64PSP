# D-030: Toolchain Pinning — Successful Compile ≠ Working

Category: Platform & Toolchain

## Decision
- Before bumping a PSP `rust-toolchain.toml`: build with new nightly, boot in PPSSPP
- Pin: `nightly-2026-08-26` with the rust-psp fork's PanicPayload fix (D-026);
  older nightlies break cargo-psp

## Why
- `rust-psp` imports unstable `core` internals
- Compiling is not evidence
