# D-007: Depth Buffer — Inverted Range

Category: Rendering Architecture

## Decision

- PSP depth buffer inverted: near=65535, far=0
- Use `sceGuDepthRange(65535, 0)` + `DepthFunc::GreaterOrEqual`

## Why

- Matches `psp` crate's documented `sceGuDepthRange` convention ("the depth buffer is inversed, and takes values from 65535 to 0")
- Not a workaround (RE-085)
- Wrong setting: everything drawn in wrong order
