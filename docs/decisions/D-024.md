# D-024: Light Colors — Preserve Source State

Category: Rendering Fidelity

## Decision
- Preserve flagged `MObjSub::light1color` / `light2color` writes as per-material state
- Light direction and both source colours affect output

## Why
- Mario's initial `MOBJ_FLAG_LIGHT2` record carries non-white ambient `(0x4C,0x4C,0x4C)` (RE-165)
- White-only conclusion missed runtime MObj graphics-heap path

## Implementation
- Pack retains:
  - stage X/Y angles
  - raw signed normals
  - zero-valid LIGHT_1/LIGHT_2 writes
  - combiner's resolved shade scale
- PSP:
  - one GE directional light scoped to fighter draws
  - literal primitives unlit
  - `PRIMITIVE * SHADE` via GE material colour
- Replaces baked-light fallback (RE-164–167)
- Matches original Dream Land comparison; no brightness approximation
- Exact cross-renderer pixels not claimed
- Physical PSP captures: RE-271, RE-341
