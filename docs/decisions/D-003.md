# D-003: Texture Formats — Keep Paletted Textures Paletted

Category: Rendering Architecture

## Decision

| N64 | PSP |
|---|---|
| CI4 / CI8 | `PsmT4` / `PsmT8` + CLUT |
| I4 / I8 | palettized greyscale |
| IA / RGBA32 | `Psm8888` |

## Why

- Paletted storage: ~77% less VRAM than naive RGBA8888
- PSP: native CLUT support
- CI4 dominates: 468 of 545 textures

## Consequences

- VRAM budget ~700 KiB after framebuffers and depth
- Full packed set exceeds it, counting:
  - mip chains (RE-053)
  - mirrored-texture pre-baking (RE-067)
  - dither blur (RE-070)
- Per-scene texture residency required (`PLAN.md`, `docs/memory.md`)
