# D-018: Surface Flags — Upper Byte State, Lower Byte Material

Category: Gameplay Model

## Decision
- `MAP_VERTEX_COLL_PASS (1<<14)`: drop-through
- `MAP_VERTEX_COLL_CLIFF (1<<15)`: ledge-grabbable
- Lower byte: `MPMaterial`
- Friction: `dMPCollisionMaterialFrictions[material] * attr->traction`

## Why
- Dream Land: three floating platforms `pass`, main platform `cliff`, ceiling and walls neither
- Four independent matches
- Spawn drop test: 158/162 land, 2-6 units below start
