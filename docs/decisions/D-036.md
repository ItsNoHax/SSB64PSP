# D-036: N64 Render-State Fidelity Must Precede Optimization

Category: Rendering Fidelity

## Decision
- IR between display-list decoding and PSP translation preserves N64 render state while SSB64 uses it
  - types: `mesh::State`/`MeshMaterial`, `pack::PrimDesc`/`TextureDesc`/`MatAnimDesc`
  - state: texture/tile, combiner shape, primitive/environment colour, geometry mode, lighting mode, alpha/blend, depth, filtering/addressing, LOD, palette/TLUT, render-pass state
- Never collapse early into `mesh + texture + basic colour`
- Merging (batching, state sorting, vertex-cache tricks; `PLAN.md` `MS8`) discards state only when:
  - correctness gate (RE-198–RE-261) passed for that state
  - rendering semantics unchanged
- Exempt: build-time vertex/index merging keeping full per-primitive material state (D-002)

## Why
- Every regression fixed in R0.6/R0.7/R0.10 was state dropped before PSP translation, never a missing GE feature
  - RE-039, RE-064, RE-068, RE-073, RE-079, RE-080, RE-092–094, RE-106
- Optimizing state away first leaves nothing to compare against the original

## Implemented
- `crates/ssb-rom/src/mesh.rs` (`State`, `MeshMaterial`)
- `crates/ssb-rom/src/pack.rs` (record formats)
- Correctness gate passed (RE-240–261); optimization starts from that baseline
