# D-010: relocData Archive — Intern/Extern Chains Through Pointer Slots

Category: Asset Pipeline

## Decision

- Intern relocations: singly linked list threaded through the pointer slots being patched
- Extern relocations: same chain, targeting other files
- Target file IDs: `u16` array after file data

## Why

- Matches `lbRelocLoadAndRelocFile` exactly
- 61,343 intern + 3,092 extern slots across 2132 files, 0 mismatches

- `crates/ssb-rom/src/archive.rs`
