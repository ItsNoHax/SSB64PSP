# D-041: PPSSPPHeadless Is the Automated Visual-Verification Runner

Category: Testing & Validation

## Decision
- Deterministic visual verification: locally built `PPSSPPHeadless` + `tools/run-ppsspp-headless.sh`.
- `tools/run-ppsspp.sh` (windowed): interactive inspection, hardware-backend experiments; not golden capture.

## Why
- Headless removes X11/window/compositor timing from the evidence path.
- Capture build requests one screenshot after a fixed deterministic tick.
  - Mechanism: PPSSPP emulator-only `emulator:` devctl; real PSPs ignore it.
- Software rendering stays default for pixel comparison.
- PPSSPP does not prove physical PSP behaviour.

## Implemented
- `psp-asset-viewer/Cargo.toml`, `psp-game/Cargo.toml` (`headless_capture`)
- `tools/run-ppsspp-headless.sh`
