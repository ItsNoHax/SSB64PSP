# D-035: Functional Validation Required, Not Just Compile

Category: Testing & Validation

## Decision
- Compiling never marks a `PLAN.md` item or milestone done
- Done: functionally validated by test, capture or trace exercising the behaviour
- State validating tier: host, PPSSPP, physical PSP

## Why
- Compiling is not working
- `PLAN.md` tracks validated work
