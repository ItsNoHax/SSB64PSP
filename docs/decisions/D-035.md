# D-035: Functional Validation Required, Not Just Compile

Category: Milestone Validation

**Decision:** Do not mark a `PLAN.md` item or milestone done because code compiles. Done means functionally validated: tests, a capture or a trace that exercises the behaviour. Say which tier validated it (host, PPSSPP, physical PSP).

**Reasoning:** Compiles ≠ works. `PLAN.md` tracks validated work.
