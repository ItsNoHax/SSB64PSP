# D-029: Debug Overlay — Software Rasteriser Required in PPSSPP

Category: Platform & Toolchain

## Decision
- Force software rasteriser via config append
- Why: `sceGuDebugFlush` paints VRAM with the CPU; PPSSPP hardware backends ignore CPU VRAM writes

## Why
- Emulator limitation, not a port bug
- Real HUD renders as GE geometry; no dependency

## Implemented
- `tools/run-ppsspp.sh --appendconfig`
