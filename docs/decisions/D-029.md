# D-029: PPSSPP Runs Default to the Software Rasteriser

Category: Platform & Toolchain

## Decision
- `tools/run-ppsspp.sh` defaults to the software rasteriser; `--backend opengl` opts out
- Forced via `--appendconfig`, then reset in `ppsspp.ini` after the run

## Why
- Same rasteriser as the golden tier ([D-041](D-041.md)): a smoke run is comparable with goldens
- Not needed for the debug HUD: the viewer's HUD is GE geometry (`psp-runtime/src/gu/hud_text.rs`) and shows on every backend
- Superseded reason: `sceGuDebugFlush` painted VRAM with the CPU, which PPSSPP hardware backends ignore (RE-014); removed in batch 188

## Implemented
- `tools/run-ppsspp.sh` (`--backend`, `--appendconfig`, `SoftwareRenderer` reset)
