# D-011: Extern Relocations — Zeroed in Pack, Patched at Runtime Load

Category: Asset Pipeline

## Decision
- Pack manifest records extern slots, leaves them zeroed
- Runtime loader: compute closure, assign offsets, apply intern and extern relocations

## Why
- Target addresses depend on runtime layout
- Same three steps as original: closure, allocate, patch

## Implemented
- `crates/ssb-rom/src/pack.rs`: manifest
- `crates/ssb-rom/src/reloc_link.rs`: closure layout and patching (RE-340)
- Checked against `lbRelocGetAllocSize` and live N64 RDRAM placement (RE-341)
- Runtime use: see `PLAN.md`
