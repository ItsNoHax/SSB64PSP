# D-026: PSP Crate Outside Workspace — Pinned Nightly + build-std

Category: Platform & Toolchain

## Decision
- PSP applications: separate Cargo projects, excluded from workspace
- Each pins `nightly-2026-08-26` in its own `rust-toolchain.toml`
- Workspace runs `cargo test` on stable

## Why
- `rust-psp` needs nightly + `-Z build-std`; depends on unstable core internals
- Pinned fork revision + matching `cargo-psp`: reproducible PSP builds
- Host CI stays fast and stable

- `psp-asset-viewer/rust-toolchain.toml`
