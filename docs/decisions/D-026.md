# D-026: PSP Crate Outside Workspace — Pinned Nightly + build-std

Category: Platform & Toolchain

**Decision:** The PSP applications are separate Cargo projects (excluded from
the workspace). They use their own `rust-toolchain.toml` pinning
`nightly-2026-08-26`; the root workspace runs `cargo test` on stable.

**Reasoning:** `rust-psp` needs nightly + `-Z build-std`; its APIs depend on
unstable core internals. The project pins its fork revision and matching
`cargo-psp`, preserving reproducible PSP builds while keeping host CI fast and
stable.

**Reference:** `psp-game/rust-toolchain.toml`,
`psp-asset-viewer/rust-toolchain.toml`, `.github/workflows/ci.yml`
