# D-013: DObj Display List Field — Undiscriminated Union

Category: Asset Pipeline

## Decision
- Field union: `Gfx*`, `Gfx**`, `DObjDLLink*`, `DObjMultiList*`, `DObjDistDL*`
- Disambiguate structurally
  - try `DObjDLLink` first: `list_id < 4` + relocated pointer
  - fall back to `Gfx*`

## Why
- Real display list cannot pass as link array: `G_VTX` word `0x01xxxxxx` > 4
- 1661 node fields resolve; 1417 convert with triangles
