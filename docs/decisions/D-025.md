# D-025: Fog — Effectively Unused

Category: Rendering Fidelity

## Decision
- Fog: not implemented

## Why
- `G_SETFOGCOLOR` appears twice in the game
  - source: `romtool scan` opcode counts
  - re-verified by reloc-anchored discovery (RE-072)
- Both uses inert:
  - no code calls `gSPFogPosition`
  - only stage setting a fog colour (`118_StageYosterSmallFile2`) never references `G_BL_CLR_FOG` in its render mode
