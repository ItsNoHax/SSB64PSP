# D-034: Two Independent Readings Must Agree

Category: Testing & Validation

## Decision
- Verify every extraction with two independent paths that must agree

| Subject | Path A | Path B |
|---|---|---|
| VPK0 | chain walk (needs correct bytes) | ROM gap (no decompression) |
| Fighter constants | ROM extraction | decomp source |
| Animation lengths | decode path 1 | decode path 2 |
| Collision | spawn drop through the swept line/line query (`romtool collide`, RE-030) | `project_floor` vertical probe, no shared arithmetic (RE-031, `romtool simulate`) |

## Why
- Wrong offset gives garbage, not a near miss
- Agreement across independent paths is the evidence
