# RE-572 — PSP-1000 memory gap vs the N64: audio, maps prefetch, figatrees

Status: MEASURED (host `memory.tsv`, pack v136, decomp source; hardware pending)
Topics: memory, audio, loader, pack, psp-1000
Relevant files: `psp-game/src/scene_load.rs`, `psp-game/src/main.rs`, `crates/ssb-rom/src/audio.rs`, `crates/ssb-engine/src/audio/synth.rs`

## Question

Why does peak use (18.8-20.6 MB) exceed the ~18 MB free on a PSP-1000, and which N64 residency rules close the gap?

- Resident = `resident_len` 5,056,928 (tables 2,964,928 + shared 2,092,000). Audio = 4,428,816 B loaded at boot, never freed (D-049); it was added after RE-475 measured 17.0 MB.
- Held bytes reproduced from the load closure to 54 B (VS select: 4,335,938 + 5,386,280 prefetched maps).
- Minimum residual over 197 golden rows 1.49 MB (f1-item-switch). The scene-dependent part up to 3.85 MB is unattributed.
- Not in peak but shrinking free: `.bss` 1,984,308 B, PRX memsz 5,650,132 B, 512 KiB stack. Derived free at `psp_main` about 18.3 MB (unmeasured).

## N64 residency (decomp)

| Item | N64 | Port |
|---|---|---|
| Audio samples | stay in ROM; DMA through 4 buffers of 1024 B (`audio.c:441-486`); audio heap 352,256 B | whole section resident (~4.14 MB samples) |
| Fighter figatrees | loaded per status into a heap sized to the largest one (13,872 B) (`ftmain.c:4623`, `ftmanager.c:57-210`) | all resident per fighter (280-470 KB each) |
| VS and training select | all 12 fighter mains (`mnplayersvs.c:4747-4765`) | same: fewer fighters at select is not N64 behaviour |
| Zako stage | 12 mains plus one largest-size figatree heap per enemy (`sc1pgame.c:2091-2121`) | all figatrees |
| Maps | cursor stage preview on landing | prefetches 9 previews and 10 wallpapers (5.39 MB) |
| General heap per scene | 2.09-2.5 MB (`nm` on the decomp ELF) | held 4.3-9.6 MB |

## Pack vs N64 bytes

- VS select + maps: texture storage 6.76 MB vs 3.77 MB ideal N64 level-0 (pow2 padding, 5551 wallpapers at 512x256, mip chains, costume duplicates); vertex 20 B vs 16 B (~0.22 MB).
- Animation scripts held for every action: 4.7 MB in Zako, 3.6 MB in clash.
- Resident region holds matanim files 1.24 MB and AnimJoint/AnimDesc tables 1.4 MB; the N64 keeps these inside per-scene files.

## Ranked options

| Option | Saves MB | Gate |
|---|---:|---|
| B maps: load preview on landing | ~5.4 select, ~3.0 training | none |
| A audio sample page cache | ~3.9 | Memory Stick small-read latency (unmeasured) |
| C per-status figatree streaming | 3.5-4.5 Zako/clash, ~1.8 VS battle | same latency gate |
| D trim resident region | up to ~2.6 | pack format bump |
| E texture dedupe and non-pow2 | 1-2 | hardware proof (D-051) |
| F lazy photo buffers, right-size display list | ~1.5 free | display-list high water |

Estimated peak MB, current / B+A / B+A+C: VS select 20.56 / 11.3 / ~10.6; training select 19.82 / 12.9 / ~12.2; Zako 19.93 / 16.0 / ~11.5; clash 18.79 / 14.9 / ~11.4.
