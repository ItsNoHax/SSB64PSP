# RE-380 — Jigglypuff in Training: the Sing notes

Status: IMPLEMENTED (decomp source, host tests, PPSSPPHeadless golden captured twice, workspace tests, both PSP builds; no physical PSP)
Topics: fighter, effect, rendering, visual-regression
Relevant files: `crates/ssb-game/src/purin.rs`, `psp-runtime/src/scene.rs`, `psp-game/src/main.rs`, `crates/ssb-capture/src/lib.rs`, `tests/golden/f1-training-purin.png`

## Question

When do the Sing notes exist, and under which transforms do their nodes
draw?

## Source

- `ftPurinSpecialHiProcUpdate` calls `efManagerPurinSingMakeEffect` when
  script flag 1 is 1, and clears the flag. Both Sing scripts set flag 1 at
  time zero, and the setters run `ftMainPlayAnimEventsAll`, so the notes
  are made on the first `proc_update`. The ground/air switches pass
  `FTPURIN_SPECIALHI_STATUS_FLAGS`, which includes
  `FTSTATUS_PRESERVE_EFFECT`. The setters pass `FTSTATUS_PRESERVE_NONE`.
- `dEFManagerPurinSingEffectDesc` (flags `0x4 | EFFECT_FLAG_USERDATA`)
  builds file 351's tree at 0x2130 with its MObjSub (0x1C20), transform
  animation (0x2270) and material animation (0x2D70). The pack already
  holds it as manager effect slot 32. The update is
  `efManagerHaveStructProcUpdate`: it plays the animation unless paused,
  and ejects the effect when its animation ends.
- The root takes kind 0x4F (79). Battle matrix functions are indexed by
  `(kind - 66) * 2` in `dLBCommonFuncMatrixList`, so kind 79 is
  `func_ovl0_800C994C`: the whole world matrix of the `user_data` joint,
  TopN.
- `efManagerPurinSingMakeEffect` appends extra transforms:
  - Node 1 (the ring, desc scale 0.01) gets kind 0x46 (70),
    `func_ovl0_800CA194`. It builds the rotation rows from the perspective
    matrix spun by `rotate.z`, with no scale.
  - Node 2 gets `RotRpyR`.
  - Nodes 3–5 (the notes) get kind 0x2A (42). In `gcPrepDObjMatrix`,
    kind 42 overwrites the MVP's X, Y and Z rows with the projection's and
    keeps the translation: a camera-facing, unscaled quad.

## Implementation

- `PurinState::sing_effect` counts the notes' played frames, from 1 on the
  frame they are made. It pauses in hitlag. `purin::sing_effect_ticks`
  returns it only in `SpecialHi` or `SpecialAirHi`.
- `psp-game` plays the tree's transform and material animations up to the
  count. It draws each mesh node as a billboard at
  `TopN(composed translation)`, with node 1 spun by its animated
  `rotate.z`. It stops once the player reports the animation ended.
- The capture scene `purin` presses Up+B at tick 20 and freezes at tick 50.

## Deviations

- TopN's world matrix is read at draw time through `Fighter::joint_world`.
- The eject is seen through the renderer's player (`StageAnimator::ended`),
  not through game state.

## Verification

A host test covers the notes starting on the first update, surviving the
air switch and stopping on `Fall`. The `f1-training-purin` golden shows
the concentric rings and three notes around Jigglypuff, and was identical
in both captures. `tools/golden.sh verify --twice` matched all 88 scenes.
Workspace tests pass with an absolute `SSB64_ROM` and one test thread.
