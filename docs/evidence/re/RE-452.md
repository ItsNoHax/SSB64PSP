## Integration and remaining scope

The portable bonus controller owns battle records, objective count and end
selection. The PSP adapter loads the course and instances, runs the shared
fighter/item world, draws target icons and announcements, then returns the
real result to the existing campaign manager and stage-clear controller.
Unsupported Platforms and Race requests still block explicitly.

Pack v96 reserves the target item slots and reuses already packed course
geometry and shared model. Previous packs must be rebuilt. Ten controller
instances replace the former eight-instance capacity. Physical stack and
memory observations have not been repeated.

The source's bonus pause map zoom, 12-tick scene fade and scene audio remain
in `PLAN.md`; the adapter currently uses the shared pause presentation.
Board the Platforms and Race scene integration follow this batch.
