# RE-348 — Static fighter map ordering, cliff reach and special contacts

Status: COMPLETE (bounded static map port; host/ROM checks, PSP builds and PPSSPP gameplay smoke; moving groups, damage recovery and physical PSP remain)
Topics: gameplay, collision, fighter, status
Relevant files: `crates/ssb-game/src/map.rs`, `crates/ssb-game/src/map_tests.rs`, `crates/ssb-game/src/collision.rs`, `crates/ssb-game/src/fighter.rs`, `crates/ssb-game/src/status.rs`, `crates/ssb-game/src/ness.rs`, `crates/ssb-game/src/captain.rs`, `tools/romtool/tests/fighter_map.rs`, `psp-runtime/src/scene.rs`, `psp-game/src/main.rs`

**Question.** Which query ordering, authored topology and contact-history rules
must survive translation of fighter map processing? Which blocked special
callbacks can consume the shared static diamond solver?

**Sources.** `mpcommon.c`, `mpprocess.c`, `mpcollision.c`, `mpdef.h`,
`ftfoxspecialhi.c`, `ftpikachuspecialhi.c`, `ftnessspecialhi.c`,
`ftcaptainspecial{hi,lw}.c`, `ftkirbyspecialhi.c`, `ftkirbythrowf.c`,
`ftcommonthrown.c`, `ftcommonfallspecial.c`, `ftcommoncliffcatchwait.c`,
`ftyoshispecial{hi,lw}.c`, `ftpurinspecial{hi,n}.c`, `lbcommon.c`, and
the existing packed fighter descriptors. Independent geometry comes from
Dream Land archive file 104 at collision offset `0x1F34` in the local US ROM.

**Findings.**

- **Ordering and identity.** Static airborne processing substeps at 250
  units and checks LWall, RWall, ceiling, floor, then cliff. Wall probes use
  swept waist/bottom/top, then current bottom-to-waist/top-to-waist edges;
  at most five distinct wall lines are retained. Correction includes line
  vertices within the diamond and keeps the most restrictive X. Adjacency
  uses original vertex IDs, with the highest matching original line ID
  winning. Coincident coordinates alone do not establish a neighbor.
- **Platform pass.** The nearest floor is queried before its pass callback.
  Rejecting that floor does not search through it for a deeper floor in the
  same substep. FallSpecial accepts downward stick below −44; Fire Fox
  rejects passable floors while its incremented pass timer is below 15.
  Existing Quick Attack and PK Thunder launch pass gates are retained.
- **Contour asymmetry.** The active short-RWall floor-adjustment branch in
  `mpProcessRunFloorEdgeAdjust` overwrites its upper-edge probe from the waist.
  The LWall branch retains the upper-edge probe. The Rust port preserves
  that source asymmetry rather than introducing a symmetric assumption.
- **Cliff reach.** The pack already contains `cliffcatch_width/height`;
  the previous gap was runtime wiring, not extraction. Cliff checks use
  facing-scaled hand reach each substep, whole-polyline endpoints, strict
  corner distance below 800 and re-grab cooldown. Material 4 is excluded
  only by the left-cliff check. The two-fighter game supplies occupied
  `(floor line, facing)` pairs. Catch/wait and first ledge-action phases
  hold their position without ordinary gravity/map motion.
- **Special callbacks.** Quick Attack's wall/ceiling halt threshold is
  135 degrees. Fire Fox redirects newly acquired contacts only and uses
  `lbCommonCheckAdjustSim2D`'s dot product divided by the sum of magnitudes;
  floor contacts already present end or bound instead of redirecting again.
  PK Thunder blast uses the active US shallow-wall rotation; impacts above
  155 degrees reflect velocity at half magnitude and enter Bound. Falcon
  Kick's wall response is gated by motion flag 1, set at frame 12 and
  replaced at frame 32; its aerial Bound clip is 30 frames. Kirby swallowed
  stars reflect off ceilings and walls through their existing reflection
  callback. Grounded ledge stops and status-specific aerial cliff gates
  include Ness thunder phases, Pound/Sing, Cutter, Dive, Bomb and jumps.
- **Corrected deferred claim.** Kirby's ThrowF and ThrowFFall use
  `ftKirbyThrowFProcMap` and ordinary landing, not cliff catch. The old
  suplex-ledges TODO was unsupported and is removed. Inhale's captured
  downward wiggle remains separate work.
- **Signed geometry.** Collision differences and axis reflections widen
  signed-16-bit vertices before arithmetic, including the `i16::MIN`
  endpoint; full-range fixtures cover overflow and winding.

**Limits.** Geometry groups are static and the fighter collision diamond is
fixed. Moving-group velocity/attachment and changing diamonds need match
inputs. Damage surface reflections, techs, StopCeil and the shared
DownBounce recovery chain remain unported; steep Ness floor impacts still
reach `DownBounceD` without an update/clip. Hanging root placement still uses
the corner, and ledge poses/TransN/clip clocks remain simplified. Egg Lay's
instant victim-placement sweep and Inhale's downward wiggle remain separate
capture work. The smoke checks existing gameplay/render integration; it does
not exercise every new callback. No full golden matrix or physical-PSP
validation was run. This batch does not close `P2`.
