# RE-372 — Luigi in Training and his Fireball palette

Status: IMPLEMENTED (decomp source, US ROM pack readback, PPSSPPHeadless golden captured twice, workspace tests, both PSP builds; no physical PSP)
Topics: fighter, weapon, texture, asset-pipeline, visual-regression
Relevant files: `tools/romtool/src/main.rs`, `crates/ssb-rom/src/pack.rs`, `psp-runtime/src/scene.rs`, `psp-game/src/main.rs`, `crates/ssb-capture/src/lib.rs`, `tests/golden/f1-training-luigi.png`

## Question

What does Luigi's Fireball draw, and how does it differ from Mario's?

## Source

- `222_LuigiSpecial1.c`: Luigi's `WPAttributes.data` is file 297 + 0x1A8
  and `p_mobjsubs` is file 297 + 0xD8. Mario's (`204_MarioSpecial1.c`)
  names the same two addresses. Both fighters draw one display list
  (0x1D8) and one `MObjSub` (0xE8).
- `wpMarioFireballMakeWeapon` sets
  `mobj->palette_id = dWPMarioFireballWeaponAttributes[index].anim_frame`.
  The row's `anim_frame` is 0.0 for Mario and 1.0 for Luigi.
- `297_MarioSpecial3.c`: `palettes[]` at 0xDC holds 0x30 (index 0) and
  0x08 (index 1). No other code writes this `MObj`'s `palette_id`, so those
  two rows bound the array to two entries.

## Findings

- Luigi's Fireball is Mario's mesh with `palettes[1]`. The pack readback
  shows red and yellow entries for index 0 and green entries for index 1.
  Entry 0 is transparent in both.
- `wpMarioFireballProcUpdate` also adds the row's `rotate_speed` (20° for
  Mario, 25° for Luigi) to the DObj's X rotation every frame. The port has
  no such field and draws both Fireballs with only the
  `wpMainVelSetModelPitch` yaw. The DObj's second transform kind is 0x47, a
  battle-scene custom matrix function (`kind >= 66`) that is not decoded.
  This deviation predates this record and applies to both fighters.

## Implementation

- `romtool` converts the file 297 list once per palette. The display list
  is shared, so Luigi's mesh uses the key (297, 0x08), the offset of the
  palette it binds. Pack v51 adds this one mesh and its texture:
  27,086,256 bytes.
- `ssb_psp_runtime::scene::fireball_meshes` resolves both meshes once.
  `psp-game` draws each Fireball with the mesh at its `MarioFireball::index`,
  so Kirby's copied Luigi Fireball also takes palette 1.
- The `luigi` capture scene spawns Luigi as the Training player and taps B
  at tick 20, as the Fox scene does. Real pad input still spawns Mario;
  Training has no fighter select.
