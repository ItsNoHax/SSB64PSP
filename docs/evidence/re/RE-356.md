# RE-356 — Stage controllers and ground hazards

Status: IMPLEMENTED (decomp, US ROM data checks, host tests, both PSP builds, PPSSPPHeadless Training goldens; no physical PSP)
Topics: gameplay, stages, collision, combat, animation, status machine
Relevant files: `crates/ssb-game/src/{hazard,fighter,map,status}.rs`, `crates/ssb-game/src/stage/`, `crates/ssb-rom/src/objanim.rs`, `crates/ssb-rom/tests/stage_controllers.rs`, `psp-runtime/src/scene.rs`, `psp-game/src/{main,play}.rs`

## Question and sources

inventing timing. Sources: `src/gr/grcommon/*.c`, `gr/grmainsetup.c`,
`gr/grvars.h`, `ft/ftmain.c` (hazard search, ground hits, hit log),
`ft/ftcommon/ftcommon{twister,tarucann}.c`, `ft/ftcommon/ftcommonstatus.h`,

## Findings

- Process order. `gcRunAll` runs priorities 5 → 0; within one priority,
  by link then creation. Priority 5: stage-object `gcPlayAnimAll`, then every
  fighter's `ftMainProcUpdateInterrupt`. Priority 4: stage controllers
  (Ground link 1), then every fighter's `ftMainProcPhysicsMap` (link 3).
  Controllers therefore read fighters after all interrupts and before any
  physics. `Fighter::tick_map` is now `tick_interrupt` + `tick_physics_map`;
  `psp-game` Training runs both fighters' interrupts, the stage slot, then
  both physics halves.
- Controllers poll `GObj::anim_frame`. `gcAddAnimAll` sets it to 0; each
  parse adds the speed; `SetAnim` rebases it to `-anim_wait`; `End` sets it to
  the leftover wait and then to `AOBJ_ANIM_END` every tick. A clip therefore
  reads `<= 0` on the tick its `End` parses. Clouds instead poll
  `MObj::anim_wait == AOBJ_ANIM_NULL`, which `gcPlayMObjMatAnim` sets on the
  `End` tick. `StageJoint::start_changed` and `gobj_frame` reproduce the DObj
  clock.
- ROM check: Whispy runs on the real Dream Land clips (file 152). The left
  front-flower start clip is 37 frames; ten wind cycles each push for exactly
  `duration − 37 − 1` frames.
- `coll_data.vel_push` (Whispy's wind) is cleared at the end of
  `ftMainProcUpdateInterrupt` and added on the first map substep only; it is
  not part of the displacement that sets the substep count. Ground, air,
  damage and captor sweeps take it.
- `dGRPupupuWhispyMouthTextures` / `EyesTextures` are played on the back and
  front flower objects, not the mouth/eyes. The ports name them by object.
- Registries: `sFTMainGroundObstacles[2]`, `sFTMainGroundHazards[1]`; loops
  visit the first `num` slots only, so clearing slot 0 of two hides slot 1.
  Kept.
- Ground hits log with handicap 9 (the POW Block uses its item's), `damage_lr
  = fp->lr`, damage index 0. Damage floors are `dFTMainGroundHitCollisionAttributes`
  by material 7–11 and 15.
- Twister and Barrel Cannon are listed as ground statuses but never set `ga`
  (the Twister leaves the ground itself first). Their map proc is
  `mpCommonProcFighterProject`: floors stop the body without landing.
- The Barrel Cannon's damage feeds only the knockback; the source never adds
  it to the percentage. Its knockback uses the US-only
  `ftParamGetGroundHazardKnockback` (no damage ratio). The angle truncates
  `rotate` to degrees toward zero.
- File data, US ROM: each `GRxxxMap` file holds `MPGroundData` at 0x14 and
  its descriptor at 0xBC. Zebes acid `{0, 16, 80, 130, 0, 30, fire}`, POW
  `{1, 20, 90, 130, 0, 30, 0}`, barrel throw `{3, 0, 90, 0, 0, 180, 0}`,
  Twister throw `{2, 14, 90, 60, 0, 115, 0}`. The acid surface is the second
  node of `llGRZebesMapAcidDObjDesc` at Y −282.725.

## Implementation boundary

Ported: Dream Land, Zebes, Kongo Jungle, Hyrule, Yoshi's Island, Mushroom
Kingdom scales and POW spawner, Saffron gate, Peach's Castle Bumper carrier;
ground hits, damage floors, Twister and Barrel Cannon statuses. Stage
objects and items are reached through the `StageObjects` port; the runtime
does not pack or draw them yet, so `psp-game` runs an empty stage slot.
Sector Z's Arwing, the bonus stages, stage items (Bumper, POW, Piranha
Plants, Pokémon), effects, rumble and audio are not ported. Twister and
TaruCann keep the previous pose (no clip mapping).
