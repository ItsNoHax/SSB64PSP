## Question

What does `gSCManagerBackupData` hold and how does the N64 validate, default
and write it, which ported scenes read or write it, and how should the PSP
keep it across boots?

## PSP deviations

- Storage: a plain `ssb64.sav` beside the pack holding the SRAM image,
  written copy by copy without truncation (D-045), not `sceUtilitySavedata`.
- Golden captures neither load nor save; only `saveunlock` and
  `saveplayers` do.
- `lbBackupApplyOptions` applies nothing: there is no audio quality switch
  and the PSP display has no centre offset. The fields are kept and saved.
- A checksum-valid copy whose `characters_fkind` or `spgame_difficulty` is
  out of range is refused like a bad checksum; the N64 would read it raw.
  Only a hand-made file can reach this.
- The anti-piracy validators that set `error_flags` are not ported (a
  genuine cartridge passes them), so their consumers stay unreached.
