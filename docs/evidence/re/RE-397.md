# RE-397 — "SUDDEN DEATH!"

Status: IMPLEMENTED (decomp source, ROM decode, host tests, PPSSPPHeadless golden captured twice, workspace tests, both PSP builds; no physical PSP)
Topics: interface, match, pack, visual-regression

## Question

Sudden death started with no announcement (RE-394 drew only its
"GO!"). What does `ifCommonSuddenDeathMakeInterface` show?

## Source

- **The letters.** `ifCommonSuddenDeathMakeInterface` makes "SUDDEN
  DEATH!" (`dIFCommonAnnounceSuddenDeathSpriteData`) from file 37
  (`gGMCommonFiles[7]`, `IFCommonAnnounceCommon`).
  - The sprites are IA8 capitals A to Z, "!" and ".", 36 to 39 texels
    tall.
  - `ifCommonAnnounceSetAttr` sets their `attr` to
    `SP_TEXSHUF | SP_TRANSPARENT`.
  - `ifCommonAnnounceSetColors` gives them a white primitive and a black
    environment, which draws the letters' chrome as stored.
- **Timing.** The thread (`ifCommonSuddenDeathThread`) sleeps 90 ticks,
  makes "GO!" and ejects its own `GObj`. So the letters show from the
  scene's first frame until the "GO!".

## Implementation

- **Sprites.** `ssb_rom::sprite::ANNOUNCE_COMMON` lists file 37's 28
  sprites from `reloc_data.us.h`. That makes 183 sprites in the pack, which is 28,051,488 bytes, SHA-256
  `0c2075edbf1e35e5eb11bdf9b9f73b2121e756775e35bb21f6ae3b2a740424f6`.
- **`ssb_game::countdown`.** Adds `SUDDEN_DEATH` (the layout) and
  `Countdown::sudden_death_letters`, which `start_go` clears.
- **Drawing.** `psp-game` draws the letters before the countdown's own
  `SObj`s.
- **Capture.** The new `vssuddendeath` scene (`vstimeup`'s rules, tick
  4,150) captures them.

## Verification

- **ROM decode.** A ROM test decodes all 28 letters as IA and checks their
  heights (Q is 37×39).
- **Tests.** The sudden-death host test checks that "GO!" clears the
  letters.
- **Golden.** The new `f1-vs-sudden-death-sign` shows the chrome letters,
  the emblems and the stock icons, and no digits before "GO!". It was
  identical in both captures. 103 of 103 goldens match.
- **Gates.** Workspace tests, Clippy and both PSP builds pass. The release
  `run` is 119,512 bytes.
