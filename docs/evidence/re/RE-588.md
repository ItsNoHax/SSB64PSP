# RE-588 — On-PSP pack build cost: host:PSP ratios, ms0 write speed, compensation budget (ROM-free release)

Status: MEASURED (PSP-2000 hardware, host)
Topics: performance, hardware, asset-pipeline, rom-free
Relevant files: `psp-runtime/src/pack_probe.rs`, `crates/ssb-pack/src/build.rs`, `crates/ssb-rom/src/blob_store.rs`, `crates/ssb-rom/src/scan.rs`, `crates/ssb-rom/src/scan/root_offsets.rs`, `crates/ssb-rom/src/filter_compensation.rs`, `crates/ssb-rom/src/psp_texture.rs`, `tools/romtool/src/main.rs`, `crates/ssb-pack/src/filter_coverage.rs`

## Findings

1. Probe: one scratch EBOOT and a host twin run the same `ssb-rom` functions on the same synthetic inputs (xorshift images and sample sets, no ROM data). Every output checksum is equal on PSP and host. PSP-2000, 6.61 ARK, PSPLink, `opt-level 3`, LTO. Host: Ryzen 9 5900X, one thread.

| Workload | Host ms | PSP ms | Ratio |
|---|---:|---:|---:|
| `solve_samples_ungated` (f64), 48x42, 4,032 samples | 10.9 | 9,055 | 830x |
| same loop in f32, targets hoisted (output bytes equal to f64) | 10.5 | 1,347 | 128x |
| f32 loop, 48x42, 32,256 samples | 81.0 | 9,949 | 123x |
| `refine_integer`, 64x64 RGBA5551, 16,384 samples | 158.4 | 20,024 | 126x |
| `pack_mipped` 128x128 T8, 256-entry palette | 10.6 | 857 | 81x |
| `pack_mipped` 128x128 5551 | 0.12 | 12.7 | 103x |
| f64 multiply/add/divide loop, 1 M iterations | 1.5 | 4,827 | ~3,200x |

   - Integer and f32: 81-128x. f64 is soft-float: 830-3,200x.
   - The f32 micro-loop overflowed to infinity and trapped (FPU overflow exception enabled): pack code on the PSP must stay finite or mask exceptions.
2. ms0 (this PSP-2000's Memory Stick, through PSPLink):
   - Write: 0.32-0.37 MB/s for 64 KiB, 1 MiB and 4 MiB chunks (8 MiB in 24.9-26.1 s; 16 MiB in 45.4 s).
   - Read: 4.2-4.6 MB/s with 1 MiB chunks (the 46,984,016 B pack in 11.3 s).
   - Writing the 47 MB pack costs about 2.3 min.
3. Golden impact of no compensation (`solve_samples` returns `None`; HEAD 17195aac, pack 46,295,888 B): 163 of 286 goldens change.
   - Changed pixels per scene: minimum 4, median 228; 18 scenes change fewer than 100.
   - Largest: `f1-vs-cpu` 397,012; `f1-vs-shield-damage` 396,520; `f1-vs-team` 391,928; `f1-vs-four` 387,072; `f1-vs-time-up` 358,860; `f1-cpufx-jolt` 303,936; `f1-training-yoster` 234,100; `r2-metal-mario-fighter` 47,236.
4. Budget for a 10-minute build on this PSP. Host seconds are taken from the batch-165 host profile of `romtool pack`, converted at 125x unless stated.

| Part | PSP time |
|---|---:|
| Pack write, 47 MB | 2.3 min |
| ROM read | about 3 s |
| Base pipeline without compensation, ~2.4 s host | 4-5 min (at 81-125x) |
| Root display-list scan, 5.0 s host | 10 min unless replaced by a committed offset list |
| Tables (`ssb-tablegen`), 0.1 s host | about 12 s |
| Exact compensation of the accepted set, 12.5 s host | 26 min |
| Its coverage (f64), 2.3 s host | 30 min or more |

   - Room left for compensation: about 2.5-4 min, i.e. 1.2-2.0 host seconds, or double that on the Media Engine.
   - Byte-identical compensation (goldens unchanged) does not fit 10 minutes. A 10-minute build drops all or part of it and changes goldens.
5. Exact cuts landed (pack byte-identical to v141; host `romtool pack` 247 s to 217 s):
   - `scan::ROOT_DL_OFFSETS`: the scan's 1,864 root lists in 135 files as committed offsets; the pack path decodes them directly. `tests/root_display_lists.rs` checks table = scan.
   - `solve_samples_ungated` in f32 with the sampler targets taken once.
6. Subset experiment: per-texture compensation cost (`convert_texture` time per texture key, all visits; coverage excluded), then packs that compensate only the cheapest keys up to a host budget, with all others plain. 71 of 1,251 texture keys end compensated, costing 14.3 s in all.
   - The costliest key: file 300 0x2490 (metal surface, texgen), 4.5 s over 14 visits.
   - Next: Yoshi's Island textures (file 123 0x7E0 from files 145 and 135, 1.7 s; file 121 0x5A8, 0.6 s); fighter files 317 and 320 at 0.1-0.9 s each.

| Kept | Host s | PSP estimate | Goldens changed | Median / max px |
|---|---:|---|---:|---|
| all 71 (today) | 14.3 | ~30 min with coverage | 0 | — |
| 48 cheapest | 1.94 | 8-11.5 min; needs the Media Engine | 31 | 400 / see below |
| 37 cheapest (landed, item 8) | 1.00 | 5.8-7.9 min (item 9) | 55 | 256 / 61,684 |
| none | 0 | 5.5-7.5 min | 163 | 228 / 397,012 |

   - The `f1-vs-*` and `f1-training-yoster` maxima of item 3 and the 48 row were counted against missing or stale local reference PNGs (`tests/golden/local/`); remeasure before citing. With 37 kept, `f1-vs-team` changes 604 px.
   - The PSP estimate is base 3.2-5 min (81-125x) + pack write 2.3 min + kept host seconds x 81-125. The kept textures' f64 coverage must also move off f64 first.
7. Coverage off f64 (pack byte-identical to v141): `filter_coverage::touched`, the UV-triangle / texel-cell test, is a 2-D separating-axis test in i64 instead of the f64 polygon clip.
   - The integer test is exact. A rational-arithmetic clip agrees on 200,000 random and lattice-snapped triangles.
   - The f64 clip missed exact single-point touches, e.g. `[[144,144],[-128,128],[208,-160]]` meets cell (2,-3) only at the corner (96,-64). No ROM primitive meets this case: the pack is unchanged.
   - f64 left on the pack path: `texgen_poses` (60 quaternion rotations per texgen basis; cheap), plus `lod_blend.rs`, `scene.rs` and `pack.rs` single sites (batch-165 inventory).
8. Landed: the owner's 37-texture subset (`filter_compensation::COMPENSATED`, `(home, data file, data offset)`).
   - Golden impact: 55 of 286 change; native pixels min 4, median 256, max 61,684 (`r2-metal-mario-fighter`), total 123,780; 18 under 100.
   - Coverage, the animated-palette index fit and the solve run only for listed textures (and the `residuals` audit). An unlisted texture packs as a rejected compensation leaves it: pack byte-identical to gating only the solve.
   - `(118, Some(110), 0xBD0)` is listed but solves nothing: file 118 draws file 111's compensated copy, cached under the same coverage hash. Without the entry that primitive packs plain (one 256 B texture moves out of the shared blob).
   - Host `romtool pack`, one thread: 122 s to 4.2-4.4 s (coverage 89.9 s and the animated fit 26.2 s gone).
   - PSP estimate: 4.3 s x 81-125 = 5.7-9.0 min, plus the 2.3 min pack write = 8-11.5 min. The upper end exceeds the owner's 10 minutes: the remaining host time is not yet broken down.
9. Host breakdown and exact cuts after item 8 (pack byte-identical; host `romtool pack`, one thread, 4.3 s to 2.6-2.75 s over three runs):

| Cut | Where | Host s |
|---|---|---|
| An unlisted texture looks up its plain cache key before converting | `pack_mesh` (`tools/romtool/src/main.rs`) | 4.3 to 3.6 |
| Cell sample dedup by a 32x32 bit set; a cell whose four corners are inside the triangle skips the per-point test; point sort and dedup by a byte radix sort on 32-bit keys (comparison sort of 8.5 M raw holdout points was 0.34 of 0.52 s) | `filter_coverage::add_cell`, `sort_dedup` | 3.6 to 3.24 |
| Index descent and `refine_integer`: partial bilinear sums per texel; histogram moved in place instead of a 1 KiB copy per candidate | `filter_compensation` | under 0.03 |
| `encode_level` memoizes `nearest_entry` per colour (direct-mapped, 1,024 slots) instead of a palette scan per texel per level | `psp_texture` | 3.24 to 2.6 |

   - Remaining listed-texture cost (81 conversions): solve 0.28 s, `refine_integer` and promotion 0.35 s, coverage about 0.35 s.
   - PSP estimate: 2.6 s x 81-128 = 3.5-5.5 min, plus the 2.3 min pack write = 5.8-7.9 min. Headroom to 10 min: a ratio up to about 178x. Not yet measured on the PSP: the portable packer runs there first.

10. Portable packer: the pack build moved from `romtool` into `crates/ssb-pack` (`no_std + alloc`; `ssb_pack::build(rom, &PackOptions, &mut dyn PackLog, &mut dyn PackObserver, &mut dyn PackSink)`); `romtool pack` wraps it. Pack byte-identical to v142.
   - Host peak memory before item 11: 145 MB resident, 198 MiB peak live heap (counting allocator, in `finish`). Holders: ROM 16 MB; every decoded archive file kept for the whole build; the pack blob (~41 MB) plus a second relaid-out copy and the 46 MB output in `finish`; audio 5.3 MB.
   - Host phase split (one thread): mesh loop 2.5 s, of it `pack_mesh` 1.6 s and `convert_texture` 1.2 s; `primitive_filter_coverage` 0.34 s; archive decode 0.08 s. Texels are 25.9 MB of the pack.
