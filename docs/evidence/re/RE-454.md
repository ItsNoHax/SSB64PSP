## Questions and evidence

How do the platform children attach to the moving course geometry, and
which contact and process ordering credit a platform?

| Finding | Source | Binding |
|---|---|---|
| All twelve courses have ten DETECT floors on distinct yakumono parents | `sc1PBonusStageMakePlatforms`; US header files 283–294 and geometry/model files 137–148 | Ground kinds 29–40. Scan floor lines in source order, mask the material byte, retain line-to-group identity and enable unanimated groups with On |
| Platform size comes from the floor's two edges | `sc1PBonusStageGetPlatformKind` | Width ≤750 selects small; ≤1050 selects medium; otherwise large |
| A platform is a child of the existing yakumono, not a replacement parent | `sc1PBonusStageInitPlatforms`, `lbCommonSetupTreeDObjs`; file 136's six model/animation tables | Keep descriptor 0 of the inserted child tree. Its joint and material clocks are independent of the parent's course path. Boarding replaces only the child, removes its material clock and immediately plays the boarded clip at frame zero |
| Empty objective parents precede the other layer-1 geometry | All twelve original `Layer1DObj` arrays; `grDisplayLayer1SecProcDisplay` | Parents 1–10 are direct children of the empty root and have no mesh. Draw inserted platform trees before the remaining geometry on link 6, separately for each task head, with the authored root matrix and child visibility flags |
| Grounded DETECT contact credits the group once | `sc1PBonusStageBonus2ProcUpdate`, priority 4; `sc1PBonusStageUpdatePlatformCount` | Observe after fighter interrupts, before priority-3 movement/item hits/death scoring. Mark the group boarded, remove one icon, and announce COMPLETE on the tenth. Timer failure already dispatched wins a final-boarding tie |
| Five courses make Bumpers from separate placement tables | `sc1PBonusStageMakeBumpers`, `dSC1PBonusStageBumperDescs` | Fox, Samus, Kirby, Jigglypuff and Ness use the shared GBumper model, file 86 offset 0x7648, with its empty root removed. Each instance plays its course root script through the common item process and retains the normal hit/swell callbacks |
| Platforms has its own follow-camera pitch | `sc1PBonusStageInitCamera` | −15 degrees; retain the shared clamped target, distance 9000, pan 0.3 and FOV 31.5 |
| Results use the same text label for both courses | `sc1PStageClearMakeTargetTextSObjs` and `func_ovl56_80132E40` | Preserve the original “Target” label with platform icons; existing bonus results preserve campaign stocks and fall totals and award Perfect only for ten tasks |

All source paths are under `refs/ssb-decomp-re/src/`; US labels come from
`include/reloc_data.us.h`. Pack v98 adds six child-tree clips and course
Bumper root clips, binds the three unboarded MObj/material tables, and
uses the layer-1 render seed. No ROM-derived assets enter git.
