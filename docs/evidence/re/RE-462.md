boot into the original's flow instead of its placeholder main menu, and
what happens where the flow reaches a scene that is not ported?

## Flow and deviations

- A production build boots `mnStartup`'s exit, the title (scene before it
  the N64 logo). Demos that are not ported are skipped along their own
  exits: How to Play goes on to Characters' demo, the auto demo and the N64
  logo (and the opening movie it would start) back to the title. The
  attract loop therefore alternates the title and Characters' demo.
- Capture builds keep a non-drawing two-step route (`CaptureIntro`,
  `CaptureMenu`) that their input scripts were timed against; every way
  back from a select now reaches the real menus. `vsplayers` presses A on
  VS Start one tick earlier for the menu's one-tic delay and still
  matches its golden.
- Not ported: the opening-only title (logo animation, slash, logo-fire
  particles), the anti-piracy flags `mn1PMode`/`mnVSMode` would set, menu
  audio, Sound Test. Bonus Practice's Sound Test message is followed by the
  title (the N64 logo skipped).
- The previous port allowed L: RETRY in the campaign's bonus pause; it is
  practice-only now, as in the source.
- The second slash of VS Options' handicap toggle was 5 pixels left of the
  source's; the N64 overlay found it.

## Verification

- Host tests: the title's timings, demo choice, boot count and fire; the
  mode select's moves, diagonal guard and draw order; the 1P mode's
  persistence and delayed load; the VS menus and the bonus select (their own
  suites); a cross-check that every sprite the seven scenes can draw is in
  its scene pack or the resident one and every scene-pack sprite is drawn;
  a ROM test of the title's baked plays. 2,065 workspace tests pass.
- N64 references (unmodified ROM; START past the N64 logo): the title, mode
  select, VS mode, VS Options, 1P mode and the Bonus 1 select. PSP
  captures `title`, `modeselect`, `vsmode`, `vsoptions`, `onepmode` and
  `bonusselect` overlay them with the same positions; colours differ only
  where the state differs (random fire colour, highlighted tab, hand).
  Item Switch has no reference (locked on a new save).
- `bonuspractice` runs Yoshi's targets with the timer at 0'03"13.
- The golden matrix at the previous commit already differs in 116 scenes;
  this batch changes only `f1-vs-mode-menu` (rebaselined: real sprites).
