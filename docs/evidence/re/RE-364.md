# RE-364 — Stage controller material animation on per-object clocks

Status: IMPLEMENTED (decomp, US ROM and pack tests, both PSP builds, full PPSSPPHeadless goldens, PPSSPP boot smoke; no physical PSP)
Topics: gameplay, stages, animation, pack, asset-pipeline
Relevant files: `crates/ssb-rom/src/{ground_obj,skeleton,pack}.rs`, `crates/ssb-rom/tests/stage_controllers.rs`, `tools/romtool/src/main.rs`, `psp-runtime/src/{scene,meshdraw}.rs`

## Question and sources

Play the material animations (`p_matanim_joints`) that the stage controllers
start on their own objects: Whispy's eyes and mouth, the Zebes acid and the
Yoshi's Island clouds. Sources: `src/gr/grcommon/{grpupupu,grzebes,gryoster}.c`,
`src/sys/objanim.c` (`gcAddAnimAll`, `gcAddMObjMatAnimJoint`,
`gcParseMObjMatAnimJoint`, `gcPlayMObjMatAnim`, `gcPlayAnimAll`),
`src/lb/lbcommon.c` (`lbCommonAddTreeDObjsAnimAll`),
`symbols/reloc_data_symbols.us.txt` and US ROM files 152, 154 and 157.

## Findings

- `grPupupuUpdateGObjAnims` passes a material table with every eye Turn and
  every mouth animation (`dGRPupupu*Anims[lr][status][1]`). Blink passes
  NULL. `gcAddAnimAll` restarts only the `MObj`s whose entry is non-NULL.
  A NULL table or entry leaves the `MObj` and its last values as they are.
- All ten Whispy scripts have one entry. The eye tables (`0x11E0`,
  `0x1270`) drive node 2's `MObj`; the eight mouth tables drive node 3's.
  Each script only steps `TextureIDCurrent` and then ends (12 to 54 ticks).
  The eye `MObj` reaches sprites 0–1, the mouth `MObj` sprites 0–3.
- The acid table (`0xBD0`) drives the child's `MObj` with one looping
  script: `TraU`/`TraV` scroll, `TextureIDNext` 1–3, `ScrU`/`ScrV` and
  `SetLFrac` 0.85–0.95. `TextureIDCurrent` stays 0. The acid primitive has
  no two-tile blend, so only sprite 0 and the tile-0 scroll are visible.
- `grYosterUpdateCloudAnim` calls `lbCommonAddTreeDObjsAnimAll` with
  `CloudSolid` (`0x670`) or `CloudEvaporate` (`0x690`), then only
  `gcPlayDObjAnimJoint`. The `MObj` parses first on the next
  `gcPlayAnimAll`. Both scripts ramp the primitive alpha and end.
- `grYosterUpdateCloudSolid` tests `mobj->anim_wait == AOBJ_ANIM_NULL`.
  The parse that reads `End` sets `AOBJ_ANIM_END`, and the play in the same
  `gcPlayAnimAll` sets `AOBJ_ANIM_NULL`. A new `MObj` starts at
  `AOBJ_ANIM_NULL`. So a cloud's line and pressure logic wait for the solid
  fade: 101 `gcPlayAnimAll` ticks from the add to the idle state.

## Implementation

- `ground_obj::MAT_ANIMS` lists the 13 tables (10 Whispy, acid, two cloud
  fades). `mat_anim_of` maps an `ANIMS` index to its table.
- Pack v46: `AnimDesc::GROUND_MAT` entries, keyed by `MAT_ANIMS` index. The
  layout does not change. Each joint's `node` names the `MatAnimDesc` of
  the `MObj` that the script restarts, or `NO_NODE` for a cloud (no packed
  mesh).
- `romtool` attaches one `MatAnimDesc` per ground-object `MObj`. It keeps
  the first script in `MAT_ANIMS` order and the widest sprite array that any
  script reaches. It declines an `MObj` where a palette script shares
  the `MObj` with another script (none do).
- `GroundObject` has its own `EffectMaterialAnimator`. `play` restarts the
  table's `MObj`s (`EffectMaterialAnimator::restart`), then parses at once.
  `advance` ticks them after the nodes. Material parses do not touch
  `GObj::anim_frame`.
- `draw_ground_object` resolves against the object's player. An `MObj`
  with no started script draws its `MObjSub` rest material, not the
  pack-lifetime clock.
- `GroundObjects::play_cloud` and `cloud_idle` hold one clock per cloud.
  `StageObjectsPort` maps `CloudSolid`/`CloudEvaporate` to them and answers
  `mat_anim_idle`. The clouds are still not drawn (TODO).

## Verification

- Absolute-ROM workspace tests with one thread: **1,201 pass**.
  `packed_ground_materials_replay_the_rom` plays all 11 object tables from
  the pack. For 240 ticks each, it compares all 15 tracks with a replay of
  the same script on the archive file, and the resolved sprite with the
  `MatAnimDesc` texture. `packed_cloud_fades_end_when_the_rom_replay_does`
  checks both fades idle after 101 ticks, the ROM replay's length, and
  that the other clouds stay idle.
- Test of the tests: with no restart in `play` or with `cloud_idle`
  always true, both tests fail.
- Pinned 1.98.0 Clippy (`-D warnings`), rustfmt and `thumbv7em-none-eabi`
  builds of engine, game and ROM pass. Both PSP release builds pass.
- `tools/golden.sh verify --twice`: **73 of 73** match. The Training
  captures end before Whispy turns or blows, so their `MObj`s keep the rest
  material. This does not show the animated textures on the GE.
- `tools/run-ppsspp.sh --crate psp-game --seconds 15` boots to the Intro
  at 60 FPS; no PPSSPP process remains. No physical-PSP run.
- Pack v46: **26,016,160 bytes**, SHA-256
  `b2dbfa6320dd5c437e5d5086de6ecc462db99bb3ab20dc95b0475d11f54fb78e`.
