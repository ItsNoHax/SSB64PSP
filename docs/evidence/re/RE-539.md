# RE-539 — VRAM vertex blocks and photo-region texture pool (PSP-2000)

Status: COMPLETE (PSP-2000 hardware frame-hash comparison, PPSSPP goldens rebaselined under D-051; pack v121)
Topics: performance, ge, hardware, goldens, link-order, memory
Relevant files: `psp-runtime/src/gu.rs`, `psp-runtime/src/meshdraw.rs`, `psp-game/src/capture.rs`, `psp-game/src/campaign.rs`, `psp-game/src/main.rs`, `psp-game/link-order.txt`

## Question

Can the lit expand's per-frame vertex blocks and the idle photo region of VRAM cut busy time on a PSP-2000 with no change to PSP output?

## Method

- `gu::ge_vertices` allocates the per-frame lit-expand vertex blocks (`expand_float_uv_corners`, `expand_corners`, `expand_sparse`) from the spare VRAM after the photo region (176 KiB on a PSP-2000, `VRAM_VERTICES`), so the GE reads them without the shared bus (RE-486). It falls back to the cached RAM block. The skin block stays in RAM (no gain in VRAM). The CPU never reads a VRAM block back. `reset_vertex_chunk` rewinds the block each `sceGuStart`.
- A texture pool lends the photo region to GE-copied textures (`sceGuCopyImage`, 2 photo slots' worth, 512 slots, armed after 60 idle frames, keyed by main-RAM texel address, dropped on a residency-generation change or a photo or wallpaper claim). `BindCache` validity is now (pack base, residency generation, pool epoch).
- 1P stage override: `onepstage=N` capture line. The 1P fixture (`capture_fixture`, `capture_objectives`) existed only in `headless_capture` builds, so hardware 1P runs never ran it. RE-537's 1P "fixture stage" numbers were default-stage numbers.
- Link order s7b: `tools/icache/layout.c` on the new code (seed 7) with `start_scene` swapped with `bind_texture_uncached`; chosen on the PSP from relinks s5/s6/s7/s9/s11/s7b against HEAD's order.
- Hardware: PSP-2000, 6.61 ARK, PSPLink v3.2.1, pack v121 (SHA-1 039f5779980d, 47,207,632 bytes). Base 131f52a plus the fixture fix against the candidate; `frame_hash` builds for output, `frame_timer` builds for time. PSPLink never hung (every run ended in a bare `reset`).
- Rejected: uncached VRAM writes, the skin block in VRAM, a per-primitive fixed cost, bind/texmap changes.
