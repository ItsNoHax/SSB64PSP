# RE-387 — Spawn facing: fighters face the stage centre

Status: IMPLEMENTED (decomp source, host test, PPSSPPHeadless goldens captured twice, workspace tests, both PSP builds; no physical PSP)
Topics: fighter, gameplay, visual-regression
Relevant files: `crates/ssb-game/src/fighter.rs`, `psp-runtime/src/scene.rs`, `tools/romtool/src/main.rs`, `psp-game/src/main.rs`, `tests/golden/`

## Question

RE-386 found that every fighter started facing right. Which way does the
original face a fighter at its spawn?

## Source

- `sc1PTrainingModeFuncStart` sets `desc.lr = (desc.pos.x >= 0.0F) ? -1 : +1`
  from `mpCollisionGetPlayerMapObjPosition`. The fighter faces left at or
  right of the stage centre, and right of it otherwise.
- The 1P game, bonus stage, auto-demo and How to Play starts use the same
  rule.
- The VS start instead faces the nearest opponent
  (`scVSBattleGetStartPlayerLR`). The port has no VS battle yet.

## Implementation

- `Facing::at_spawn_x` holds the rule.
- `FighterScene::at_spawn` applies it, so the rule reaches the `psp-game`
  player, the dummy and the asset viewer's fighter.
- `romtool jumptest` applies it too, so its traces still match
  `psp-game`.
- On Dream Land the player spawns at x = 0, so the player now faces left,
  toward the dummy at (−1397, 904).
- The grab scene's left tap at tick 98 only turned Mario around. With
  Mario already facing left, the tap dashed him off the platform, so it
  is gone.

## Verification

- **Host test.** `a_spawn_at_or_right_of_centre_faces_left` covers the
  rule at x = 0, on either side of the centre.
- **Rebaselines.** 47 goldens changed, each identical in both captures:
  - 28 `psp-game` Training scenes, with every player starting to the left;
  - 19 asset-viewer scenes, whose only difference is a Mario-sized box.
  `f1-training-stage-select` is unchanged: both Hyrule Castle spawns are
  at x < 0.
- **Contact sheets.** Each special-move scene still shows its projectile
  or effect. The PK Fire spark and the Final Cutter wave now travel left.
  The wave runs off the top platform's left end in `f1-training-kirby`.
- **Logs.** `PPSSPPHeadless --log`:
  - `jab`: the jab still lands (`DamageHi1`, damage 2);
  - `grab`: without the turn tap, the catch lands (`CatchWait`, dummy
    `CaptureWait`).
- **Character select.** On Peach's Castle the dummy now faces left toward
  Kirby.
- **Full run.** `tools/golden.sh verify --twice` matched all 95 scenes.
  Workspace tests pass with an absolute `SSB64_ROM` and one test thread.
