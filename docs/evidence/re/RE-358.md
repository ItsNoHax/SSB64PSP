# RE-358 — Animated RSP cache vertices close fighter joint seams

Status: IMPLEMENTED (decomp, US ROM, host tests and PPSSPP software; no physical PSP)
Topics: geometry, fighter, animation, pack, rendering, visual-regression
Relevant files: `crates/ssb-rom/src/{mesh,pack}.rs`, `tools/romtool/src/main.rs`, `psp-runtime/src/meshdraw.rs`, `docs/decisions/D-014.md`

## Symptom and original behavior

The Dream Land goldens show holes at Mario's knees. RE-026 and D-014
already establish that `G_VTX` transforms slots when they are loaded and
the RSP cache survives across joint lists. The rest-pose-only rebase had
remained in use after fighter animation was introduced.

`ftDisplayMainDrawDefault` (`refs/ssb-decomp-re/src/ft/ftdisplaymain.c`,
lines 753–839) walks joints in one display-list stream, preparing each
joint matrix before its post-matrix list. Pre-matrix pair lists run under
the parent matrix. Triangle commands reference already-loaded slots.

Independent US ROM check, file 296, graph `0x2200`:

| Joint | List | Vertex load | Borrowed slots |
|---|---|---|---|
| Left thigh, node 15 | `0x1E80` | 11 at slot 0 | — |
| Left shin, node 16 | `0x1F10` | 6 at slot 5 | 0–4 from node 15 |
| Right thigh, node 20 | `0x2040` | 11 at slot 0 | — |
| Right shin, node 21 | `0x20D0` | 6 at slot 5 | 0–4 from node 20 |

Each shin draws 15 triangles. Five of its eleven mesh vertices belong to
the thigh. Moving all eleven under the shin matrix tears the connecting
ring, exposing the stage through the knee. The defect is shared-joint
geometry, not missing ROM triangles or a texture/palette problem.

## Implementation

`MeshVertex::binding` preserves the borrowed slot's loading item and its
original integral position. Deduplication includes this provenance. The
packer maps sequence items to graph nodes, including the parent's space
for pre-matrix pair lists and the object root sentinel. Both base and
costume conversions use this mapping.

Pack v43 grows `MeshDesc` from 24 to 28 bytes with an optional blob offset.
Binding records are eight bytes per vertex: loading node plus three source
position components. There are 391 borrowing meshes and 5,353 vertices in
their binding arrays. Old packs are rejected by the existing version gate.

Posed drawing copies only a borrowing mesh into frame-owned GE arena
memory. Each borrowed position uses `inverse(current posed world) *
source posed world`. Joint translations are normalized by 32768 in the
pack, so the relative translation is converted back to vertex units.
Normals use the relative inverse transpose. UVs, material colours,
indices and draw order are retained. Empty-pose/static drawing uses the
existing baked rest geometry.

Positions round to PSP i16 units and reconstructed normals round to signed
bytes. This retains the existing GE format's quantization; it is not a
claim of exact N64 subpixel rasterization or physical-PSP equivalence.

Pack: **25,288,432 bytes**, +57,200 from v42; SHA-256
`2dd4324b8e7b620f802dcc3e93e9f1017b7e88e3a4cb79c2dd9ae72167428e48`.
All 1,881 texture descriptors (apart from relocated blob offsets), texel
bytes and palette bytes match v42. Generated pack data is not committed.

## Verification and visual attribution

- The shared-cache conversion test checks source positions and ownership.
- A pack roundtrip test checks independent translation/rotation of a
  borrowed position and normal, preserving UVs and material colour. It
  also preserves the full signed-normal range, including -128.
- `mario_knees_retain_thigh_cache_vertices` converts the real ROM graph
  and verifies each shin's five thigh-owned vertices and 15 triangles.
- Workspace tests with the absolute `SSB64_ROM` and one test thread:
  **1,192 pass**, including 518 gameplay tests. Clippy with warnings
  denied, rustfmt and the ROM crate's thumb `no_std` check pass. Both PSP
  release builds pass; interactive outputs are restored after captures.
- Pack strict check: 1,881 textures, 3,353 meshes, 8,371 primitives and
  3,148 nodes; **zero unresolved resources**. Training golden captures
  supply the PPSSPP integration smoke. No physical-PSP run.
- Control: temporarily disabling only the posed binding reconstruction
  with the new pack reproduces **all 73 old goldens twice**, exactly.
  The control edit is reverted.
- Enabled captures change 40 goldens; all 73 scenes match their repeat
  capture. Visual review shows closed knees on Mario/Luigi/Metal Mario,
  closed Pikachu torso and limb seams, and smaller seam/lighting changes
  on DK, Link, Yoshi, Kirby and Jigglypuff. Stage-view masks cover the
  small Mario model; Training changes cover fighter joints. Textures and
  stage geometry are unchanged. Per-scene counts below are at 2×.
