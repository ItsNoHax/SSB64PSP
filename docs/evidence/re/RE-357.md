## Map files and label table

`MPGroundData::map_nodes` points into a separate object file. Controllers
subtract `llGR*MapMapHead` from that pointer and add object/clip labels to
the base. Applying these labels to the header file reads unrelated bytes.

| Stage | Header file | Object file / map head | Graphs | Display links |
|---|---:|---|---|---|
| Dream Land | 255 (`0xFF`) | 152 / `0x10F0` | eyes `0x10F0`, mouth `0x1770`, back flowers `0x2A80`, front flowers `0x31F8` | 4, 4, 4, 16 |
| Kongo Jungle | 261 (`0x105`) | 158 / `0xA98` | barrel `0xA98` | 6 |
| Saffron City | 264 (`0x108`) | 160 / `0x8A0` | gate `0x8A0` | 6 |

`ground_obj::OBJECTS` binds these six existing graphs. `ANIMS` is a stable

animation tables for the back/front flowers, not mouth/eye material clips.
The pack builder checks each resolved map-head label and rejects missing
graphs, objects or scripts. It appends 29 clips and 72 animated-node entries
after effect animations; the existing graphs are not duplicated.

## Clock and display semantics

- `gcAddDObjAnimJoint` resets active tracks while pose and flags persist.
  A NULL table entry stops that node without resetting either.
- `gcAddAnimAll` / `gcAddAnimJointAll` zero the GObj clock. Immediate
  `gcPlayAnimAll` parses every node in tree order. Each parser may write
  that clock; the last writer wins. `End` reads nonpositive on its parse
  tick; `SetAnim` rebases loop clocks (RE-356).
- Barrel Fill/Shoot replace child 1 alone and immediately parse/play it.
  They leave the root and other tracks running and do not zero the GObj
  clock; only the selected parser may write it.
- Ground object `gcPlayAnimAll` runs at priority 5 before fighter
  interrupts; stage controllers run at priority 4 before fighter physics.
  Training follows this order and uses `StageObjectsPort` for its three
  former `NoObjects` call sites.
- `dGRDisplayDescs` uses links 4, 6, 13, 17. `gcAddGObjDisplay` appends
  same-priority objects at the link tail. Controller objects created after
  layers draw after the layer on the same link. Front flowers on 16 draw
  between layers 13 and 17. Animated drawing respects mesh/subtree flags.

Training constructs `GroundObjects` from `StageDesc::source_file` and maps
Dream Land to `StageKind::Pupupu`, carrying map points and bottom bound into
`StageInit`. Other stage kinds retain an empty controller slot. Whispy's
placement lives in child 1 (X = −525 game units), not its zero-position root.

## Flower discrepancy: cached ST writes

Initial Training captures showed horizontal texture streaks through the
flower beds. All 29 clips' packed poses, flags and clocks matched original
file replay; the discrepancy was in the display-list texture coordinates.

Flower head lists `0x28B0`, `0x29A8`, `0x2F30`, `0x3028`, `0x3120`
rewrite ST on vertices 0 and 1 loaded by their parent stems. Example:
`02140002 0FFF0000` at file 152 `0x2938` writes vertex 1's S10.5 pair.
`PR/gbi.h` defines opcode `0x02`, field `0x14` and a doubled cache index.
These commands previously decoded as ignored `Other`s.

The converter now replaces the cached, already-scaled signed ST pair,
preserving the loading space. It does not apply `G_TEXTURE` scale again.
A synthetic shared-cache test covers negative T, inherited position and
the unchanged earlier draw. Other modify-vertex fields remain untranslated.

The same command occurs in Donkey's file 317 (e.g. `0x23B0`/`0x23B8`) and
Link's file 324 (`0x2488`/`0x2490`). Full-matrix review found three additional
changes: DK shoulder/arm texture regions and small Link neck/arm texture
regions in costumes 0 and 1. The rest-pose vertex-rebase limitation remains
(D-014); whole-renderer original-game equivalence is not claimed.
