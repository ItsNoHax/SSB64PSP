Relevant files: `crates/ssb-rom/src/{ground_obj,pack}.rs`, `crates/ssb-rom/tests/stage_controllers.rs`, `crates/ssb-game/src/stage/{mod,yoster,inishie,tests}.rs`, `tools/romtool/src/main.rs`, `psp-runtime/src/{scene,meshdraw}.rs`

## Question and sources

Draw and move the controller objects that are not built from a `DObjDesc`
array: the Yoshi's Island clouds, the Mushroom Kingdom scales and the
Castle ground. Sources: `src/gr/grcommon/{gryoster,grinishie,grcastle}.c`,
`src/gr/grmodelsetup.c`, `src/sys/objanim.c` (`gcSetupCustomDObjs`,
`gcDecideDObj3TransformsKind`), `src/sys/objdisplay.c` (case 48 and the
`gGCScaleX` writes), `src/relocData/{154,155,156}_*.c`,
`symbols/reloc_data_symbols.us.txt` and US ROM files 154, 155 and 156.

## Findings

- `map_nodes` lands in file 154 at `0x100` (Yoshi's Island), 155 at
  `0x5F0` (Mushroom Kingdom) and 156 at `0x0` (Castle).
- **Clouds.** Each of the three cloud GObjs is `llGRYosterMapMapHead`, a
  four-node graph (root and three children), built by `gcSetupCustomDObjs`
  with `nGCMatrixKindTra` only. Under each child the controller adds a
  `DObj` drawing `llGRYosterMapCloudDisplayList` (`0x580`) with
  `nGCMatrixKindTra` and `nGCMatrixKind48`, and `MObjSub` table `0x4B8`
  (one `MObj`, `0x4C0`). Its root starts at the collision group's
  translation (groups 1–3) and the controller writes only its Y.
- The clip `llGRYosterMap_1E0_AnimJoint` (table `[NULL, 0x1F0, 0x21C,
  0x264]`) writes only `ScaX`/`ScaY` on the three children. A
  `nGCMatrixKindTra` matrix ignores scale, and only scale kinds multiply
  `gGCScaleX`, so the clip never changes a drawn matrix. The decomp's own
  comment says so. The port does not pack or play it. The rest scale 1.093
  on two children is likewise invisible; the port composes these nodes
  translate-only.
- The cloud display list draws one 638×600 quad at Z −150. Its render tile
  mirrors and clamps both axes (mask 5) on a 32×32 I4 texture with ST
  0..64. The pack bakes it as a 64×64 mirrored texture.
- **Scales.** `llGRInishieMapScaleDObjDesc` (`0x380`) is the pulley and
  strings: five nodes, all `nGCMatrixKindTra` (`dGRInishieScaleTransformKinds`),
  identity rotation and scale. Each platform is one `DObj` drawing
  `llGRInishieMapMapHead` (`0x5F0`) with `nGCMatrixKindTra`, placed at the
  `ScaleL`/`ScaleR` map object.
- `scale[0].string_dobj` is node 4 with `string_length = n0.y + n3.y`
  (2010 − 57.75009); `scale[1]` is node 2 with `n0.y + n1.y`
  (2010 − 57.751007). The controller writes each string node's Y as its
  platform's Y minus that length, so the string node's world Y equals its
  platform's.
- `llGRInishieMapScaleRetractAnimJoint` (`0x734`) is `SetFlags(2)`, wait
  2, `SetFlags(0)`, wait 2, loop: the platform blinks while it retracts.
  The controller ends it with `anim_wait = AOBJ_ANIM_NULL` and
  `flags = DOBJ_FLAG_NONE`.
- **Castle.** The ground GObj is one `DObj` with no display list and no
  display. `map_nodes` is itself the joint table: one script (`0x4`)
  ramping `TraX` 0 → −1050 (599) → 1050 (1200) → 0 (600), holding 2400
  frames, then looping. Only the Bumper reads it.

## Implementation

- `ground_obj::OBJECTS` gains `Cloud` (three instances, a `Leaf`),
  `ScaleStrings`, `ScalePlatform` (`Build::Dl`, two instances) and
  `CastleGround` (`Build::Empty`, `NO_LINK`). `translate_only` marks the
  `nGCMatrixKindTra` objects. `ANIMS` gains `ScaleRetract` (slot 30,
  node 0) and `CastleGround` (slot 31, table). The cloud fades in
  `MAT_ANIMS` now drive the leaf graph.
- `romtool` adds a one-node graph for each `Build::Dl`/`Build::Empty`
  label and for each leaf, keyed by the label. A leaf node gets id
  `0x2000`: the same `Tra` + `Kind48` pair the controller adds. The leaf's
  `MObjSub` table is paired with it once it parses for one node.
- `GroundObjects` holds instances. `GroundObjects::new` finds the stage's
  `map_nodes` file through any of its packed clips or material tables,
  then each object by label. A cloud's fades restart its leaf `MObj` on
  the cloud's own `EffectMaterialAnimator`; `cloud_idle` reads that clock.
- `StageObjects` gains `set_translate`, `node_translate` and
  `set_node_translate_y`, and `StageObj::ScaleStrings`. Yoshi's Island
  places each cloud at its group and writes its Y. Mushroom Kingdom places
  the platforms each tick and hangs the string nodes in Wait and Retract,
  as the source does. `StageObjectsPort` maps every object to its instance.
- `draw_ground_object` draws each leaf once per child of the root, at that
  child's matrix.
