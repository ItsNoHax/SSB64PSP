## Source discoveries

`itegg.c` and `itcapsule.c` share the light-container states: init, wait,
fall, hold, thrown, dropped and explode. Init/fall/drop use the common
dropped-map solver and return its random-despawn result. Link Bomb's
callback ignores that result; copying its wrapper would keep containers
alive incorrectly. Capsule's drop setter leaves `is_damage_all` alone;
Egg's setter enables it. Waiting clears ownership and restores pickup.

Egg's explosion initializer calls the Capsule attack-event table, then
its updates use the Egg table. This source asymmetry is preserved. Both
initialize at timer zero with damage 30 and radius 350; Capsule changes
at timers 2 and 4 and deletes at 6. Egg changes at 4 and 6 and deletes at
8, emitting shell fragments. The terminal authored event is unreachable
because deletion precedes its application. Explosion clears owner stats,
disables reflection/hop/set-off, hides the model and makes fire damage,
the 1.4-scale common explosion and magnitude-1 quake.

The ROM's file-251 attributes at `0x50` (Capsule) and `0xACC` (Egg) have
different map boxes, damage, base knockback, velocity and spin percentages.
The test reads the original fields and event tables, rather than checking
only the translated constants. Capsule's spin percentage is evaluated as
`120.0 * 0.01`, preserving the source float operation.

## Maker, switches and search ordering

Normal-item switches use the original kind bits. Ground Chansey's
`itGLucky` egg gate requires appearance other than None and bit 3. The
callback now allocates the real Egg immediately in the shared 16-slot pool,
projects its collision from the parent, and makes swirl script `0x69` and
dust after successful allocation. Its two velocity draws, allocation retry
and one-egg count are retained. Ground GLucky does not make MLucky's extra
direction RNG draw. A new child joins the link immediately; this frame's
main-process snapshot skips its update, while later searches see it.

`itManagerSetupContainerDrops` builds cumulative weights for utility kinds
4–19 and sentinel 32. The sentinel receives ten percent of the utility sum,
truncated and clamped to one. An empty table draws no RNG. The source treats
a selected utility as success even if its maker cannot allocate.

The application enables only supported Capsule/Egg bits at Middle rate.
Its utility table is empty, so opening uses the original explosion fallback.
The weighted selector is infrastructure; utility makers, appearance actor,
heavy containers and heavy fighter statuses are not implemented here.

Light containers enable the previously unreachable item–weapon clash
branch in `itProcessSearchHitWeapon`. It runs in weapon link order before
the item hurtbox test, applies both priority comparisons and victim records,
and defers the weapon's set-off callback through the existing clash queue.
Effects from item collision callbacks flush after item resolution, in
addition to the existing item-main flush.

## Rendering and frame-zero playback

Capsule uses archive file 86's four-node graph at `0x670`: a loose maker
replaces root translation; a held item composes the descriptor under the
fighter's normalized hand joint. Egg uses graph `0x104A0`, animation table
`0x10550`, child-1 kind-46 billboard and child-2 scale script `0x1055C`.
Root Z spin transfers to the billboard child.

The first Egg clock test exposed a frame-one offset in ordinary
`StageAnimator::start`. The item manager uses raw `gcAddAnimAll` followed by
its first `gcPlayAnimAll`, whose initial sample is frame zero. A separate
`start_changed` entry preserves the existing stage clocks and gives Egg
the source first sample. Its 200-tick packed replay now agrees bit-for-bit
with `StageJoint::start_changed` on the original ROM script.

Item visual capacity grows from four to the shared pool's sixteen slots.
The existing field-by-field heap initializer avoids a large stack temporary.
Pack v82 adds Egg's animation slot; its layout is unchanged.
