## Race packing correction and ROM evidence

RE-446's claim that Race's ground, barrel model and pieces were absent
from the pack was incorrect. The existing stage/archive discovery already
includes file 0x127, its file 0x95 render layers and collision, the file
0xA2 descriptors/barrel model, and shared barrel pieces. The missing part
is the item runtime binding for the four independently animated Bumpers.

| Data | US ROM evidence |
|---|---|
| Race ground | Header file 0x127 at 0; render layers 0 and 1 present; 34 collision lines |
| Bumper placements | File 0xA2 at 0, skip first descriptor, then four translations |
| Bumper scripts | File 0xA2 pointer table at 0x110; active scripts 0x124, 0x150, 0x18C, 0x1C8 |
| Bumper model | Shared `itGBumperMakeItem` tree in ITCommonData file 86 at 0x7648, rather than the descriptor container |
| Bomb barrel model | File 0xA2 at 0x788, already packed |
| Handicap table | RDRAM 0x8012C830, ROM 0xA8030; 40 pairs, checked bit for bit |

Pack v92 adds four item-root clips. Conversion resolves the model and
script from their distinct archive files. Each item starts its own clip
on creation and advances through the existing item animation port.
`StageSetup` loads Race's four placements from the packed descriptors.

## Boundaries and deviations

- Original blocking overlay calls become scene requests. `Session`
  connects those requests to shared battle/KO machinery, collects the
  result once, and exposes replacement fighter descriptions.
- An enemy's KO uses team blast bounds and requests a replacement when
  its KO wait ends; the human retains the normal stock/rebirth branch.
- Victory uses the original 45-tick Set hold and requests a zoom;
  COMPLETE uses the common 90-tick announcement and three-tick return.
  Its letters use the existing ANNOUNCE_COMMON sprite table.
- With zero recorded enemy defeats, the port skips last-defeat predicates
  instead of reproducing the source's out-of-bounds access.
- The PSP campaign frontend, intro/continue/stage-clear/ending/challenger
  presentation, live bonus-stat hooks, separate bonus-stage controllers,
  Master Hand fighter logic and `sc1pgameboss.c` wallpaper/fade controller
  remain unported. The barrel's model is packed but its PSP draw dispatch
  remains absent. This batch does not make 1P selectable or playable.
- Backup records and write requests are portable data; physical save
  persistence and message-scene unlock writes remain host work.
