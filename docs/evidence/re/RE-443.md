## Source findings

| Behaviour | Source and implementation |
|---|---|
| Poké Ball material | `itMBallOpenAddAnim`, called by Thrown/Dropped, adds file 86 + 0x9520 to the closed ball's MObj. Its eight textures cycle until `itMBallOpenClearAnim`. A separate mesh variant avoids replacing the fighter-entry table. The root-script clock records both events. |
| Rays | `itMBallOpenInitVars` makes `efManagerMBallRaysMakeEffect`; Open/OpenAir follows the ball until the release callback. EFDesc flags 4 lack USERDATA: the maker selects the no-struct process despite the descriptor's HaveStruct callback. Link 10, file 85 + 0x0628, lifetime 51 plays including the maker's play. The item does not eject the effect at release. |
| Status materials | Goldeen: node 2, script 0xB90C; Charizard: node 1, 0xD688; Beedrill: node 2, 0xE12C; Starmie: node 1, 0x11338. Each starts on the status clock and receives the status's first play. |
| Link 18 | `gcMoveGObjDLHead` moves Starmie/Hitmonlee on creation, Snorlax on Fall, and Clefairy's corresponding imitations. The port records the move clock and draws newest moves first, with reverse item order for same-pass moves. Starmie/Hitmonlee retain their normal callback. |
| Conditional modes | Snorlax Fall and Clefairy's moved-display callback select AA_XLU_SURF on head 0, without depth. Clefairy's normal callback selects AA_ZB_TEX_EDGE. The swarm weapon uses the moved-display wrapper. Converted variants seed the callback state before the ROM's own commands. |
| Clefairy Fall scale | `itKabigonFallInitVars` sets its root X/Y scale to 5.2. The camera-relative draw path now includes the item scale, as the world-space Snorlax path already did. |
| Rock textures | `itIwarkWeaponRockMakeWeapon` selects texture ID 0..2. The MObj's image pointers are 0xA950, 0xA8C8 and 0xA840. Three mesh variants preserve the original images and weapon state. |

## Correction to RE-435

`lbCommonDObjScaleXProcDisplay` calls `lbCommonDrawDObjScaleX` in
`src/lb/lbcommon.c`. Its matrices, MObj commands and direct lists write
explicitly to `gSYTaskmanDLHeads[1]`. RE-435's head-0 diagnosis was wrong.
The affected graphs are FlyOrbs (83 + 0x7E80), CommonSpark (83 + 0x8FA0:
FlySparks and Star Rod) and ShockSmall (84 + 0x1500). Their effect links
install CLD before drawing. `romtool` marks their direct lists HEAD1 and
seeds EffectCld, preserving later commands in the list. Black spark squares
disappear without a renderer heuristic. The head-1 graph census grows
from 104 to 107; the number of lists writing their own mode remains 3.

The port identifies the rays by sequence rather than a reusable pool slot.
Following an ejected effect cannot move its replacement. This preserves
normal behavior and bounds an early-ejection case safely.

## Original-game observation

A temporary decomp build boots Training on Dream Land with two Marios and
makes Onix, Snorlax and Beedrill from owned balls at Mario + (-900, -400,
600) X and +109 Y. Mupen64Plus frames 40, 80, 120, 135, 160, 228 and 240
show Onix's rise, Beedrill's wing frames/swarm and the textured rock shower.
The PSP's `trainingpokemonc@60/240` shows the same qualitative visuals.
Snorlax is visible above the original frame; its full fall is covered by
the PSP control and source state, rather than an aligned original capture.
Damage, camera and spawn clocks differ; this is not event-aligned gameplay
equivalence. Scratch captures remain outside the repository.

Both temporary source patches are restored. The rebuilt original ROM
matches SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`.
