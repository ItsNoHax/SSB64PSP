# RE-342 — Weapon staling

Status: COMPLETE (decomp source, host tests, both PSP builds, PPSSPP goldens; no hardware input test)
Topics: weapon, gameplay, combat
Relevant files: `crates/ssb-game/src/stale.rs`, `crates/ssb-game/src/weapon.rs`, `crates/ssb-game/src/link.rs`, `psp-game/src/main.rs`

**Question.** How does the source stale a weapon's damage and feed the
owner's stale queue?

**Source.**

| Step | Source |
|---|---|
| Capture | `wpManagerMakeWeapon`, fighter parent: `attack_coll.stale = ftParamGetStale(fp->player, fp->motion_attack_id, fp->motion_count)`, and the motion ID and count are copied. A weapon made by a weapon or item copies its parent's; a parentless weapon uses `WEAPON_STALE_DEFAULT` and no motion. Reflection changes the owner, not the stale. |
| Damage | `wpMainGetStaledDamage` @ 0x80168128: `damage * stale + 0.999`, always, then `ftParamGetCapturedDamage` for a held target. Shield, reflector and hit paths all use it. |
| Queue | `ftMainUpdateDamageStatWeapon` calls `ftParamUpdateStaleQueue(wp->player, fp->player, motion_attack_id, motion_count)` when the damage registers. |

**Implementation.** `WeaponSpawn::stale` carries `WeaponStale::of(owner)`
from the motion-script event that makes the weapon. `WeaponPool` keeps one
per slot (both Yoshi stars share their spawn's) and stales every weapon
hitbox before the shared hit path. A registered damaging hit is held per
slot until `WeaponPool::record_landed`, which `psp-game` calls for both
fighters right after `apply_hits`, so the queue changes in the same frame.
Link's Spin Attack weapon is fighter state: it stales by Link's current
motion when it connects and records that motion.

**Deviation.** The Spin Attack takes its stale at contact, not creation.
The two differ only if Link lands another hit during the same
`SpecialHi` motion.

**Verification.** New host test: a second Yoshi egg throw with the first
in the queue captures stale 0.75 and deals `14 * 0.75 + 0.999 = 11`; only
the owner's `record_landed` adds the motion. The Mario Fireball spawn test
now expects the neutral-B motion. All 72 goldens match: no scripted scene
lands a weapon hit (RE-341).
