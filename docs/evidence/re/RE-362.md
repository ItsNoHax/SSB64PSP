# RE-362 — Match stage loader: kinds and hazard descriptors from the pack

Status: IMPLEMENTED (decomp, US ROM and pack tests, both PSP builds, full PPSSPPHeadless goldens, PPSSPPHeadless Zebes probe; no physical PSP)
Topics: gameplay, stages, pack, asset-pipeline
Relevant files: `crates/ssb-rom/src/{stage,pack}.rs`, `crates/ssb-rom/tests/stage_controllers.rs`, `crates/ssb-game/src/stage/mod.rs`, `tools/romtool/src/main.rs`, `psp-runtime/src/scene.rs`, `psp-game/src/main.rs`

## Question and sources

Build `StageInit` for any packed VS stage instead of Dream Land alone
(RE-356, RE-357). The runtime has only the pack, so the stage kind and the
hazard descriptors must reach it through packed data. Sources:
`src/mp/mpcollision.c` (`dMPCollisionGroundFileInfos`),
`src/gr/grcommon/{grzebes,grinishie,grjungle,grhyrule}.c` and
`symbols/reloc_data_symbols.us.txt`.

## Findings

- `dMPCollisionGroundFileInfos` rows 0–8 are the VS stages in `GRKind`
  order. The US `GR*Map` files are Castle `0x103`, Sector `0x106`, Jungle
  `0x105`, Zebes `0x101`, Hyrule `0x109`, Yoster `0x107`, Pupupu `0xFF`,
  Yamabuki `0x108` and Inishie `0x104`. Every file holds its
  `MPGroundData` at `0x14`. `StageDesc::source_file` identifies the kind,
  so the pack needs no kind field (`stage::vs_ground_kind`).
- All four hazard labels resolve to `0xBC`, directly after the header:
  `llGRZebesMapAcidGRAttackColl`, `llGRInishieMapPowerBlockGRAttackColl`,
  `llGRJungleMapTaruCannThrowHitDesc` and `llGRHyruleMapTwisterThrowHitDesc`.
  Both structs are seven `s32` values. The stage kind decides which struct
  the controller reads (`StageKind::hazard_descs`).
- `grZebesMakeAcid` subtracts `llGRZebesMapAcidDObjDesc` from `map_nodes`
  and adds the label back, so the acid graph is the `map_nodes` target
  (file 157, `0xB08`). The surface is node 1's translation Y, −282.725.

## Implementation

- Pack v44: `StageDesc` grows from 72 to 104 bytes. It gains the seven
  `hazard` words and `hazard_surface_y`, both zero for stages that do not
  read them. `romtool pack` fails if Zebes has no acid graph at
  `map_nodes`. `Pack::stage_of_file` finds a stage by its `GR*Map` file.
- `psp-runtime::scene::StageSetup` reads the kind, map points, bottom
  bound and hazard data, and lends a `StageInit`. Training uses it for
  every stage and falls back to `Stage::none()` for non-VS stages. The
  former Dream Land check is gone. Training still loads stage index 0.

## Remaining scope

The game has no stage selection yet; Training loads Dream Land. Zebes
acid still has no object or drawing (`StageObj::Acid`), and the POW Block,
barrel and Twister need their stages' objects or items before a match can
use the descriptors. The RE-357 limits on the remaining controller geometry
and material animation still apply.
