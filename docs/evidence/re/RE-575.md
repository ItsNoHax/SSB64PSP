Status: MEASURED (64 MB Slim PSP, PSPLink, ms0 pack v137 48,950,096 B, 2 runs per arm; base = HEAD ecfbe27d + instrumentation)
Topics: performance, hardware, loader, audio, memory
Relevant files: `psp-runtime/src/scene_files.rs`, `psp-runtime/src/sample_stream.rs`, `psp-game/src/scene_load.rs`, `crates/ssb-game/src/opening/mod.rs`

## Mechanism

| Item | Value |
|---|---|
| Before | `sceIoReadAsync`, one 64 KiB chunk per safe-point poll (~1 per frame) |
| After | `sceIoRead` on the streamer thread (priority 0x1E, no new thread or stack): up to 4 chunks per frame |
| Hold | Game-thread read (`read_sync`) stops background chunks after the one in flight; the safe point resumes them |
| Streamer loop | Serve all queued audio pages, then one loader chunk: a page waits at most one chunk |
| Opening | `first_rows(kind)` clips (Run, Clash, Yoster, Cliff, Standoff, Yamabuki) read as scene files with the prefetch |

- Only read timing changes; gameplay timing does not (RE-572 option C stays for later statuses).
