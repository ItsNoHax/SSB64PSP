# RE-517 — 2D sprite edge fringe: one-ring RGB bleed baked at pack time

Status: COMPLETE (PPSSPP; host model)
Topics: rendering, sprites, textures, pack
Relevant files: `crates/ssb-rom/src/sprite.rs`, `crates/ssb-rom/src/sprite_fringe.rs`, `crates/ssb-rom/examples/sprite_fringe.rs`, `crates/ssb-rom/src/pack.rs`, `tools/romtool/src/main.rs`

## Question

The PSP draws sprites at scale 1.236 with Linear filtering; transparent texels are mostly black, so edges show a dark fringe (RE-515). Which pack-time or filter change gets closer to the N64?

## Findings

- ROM transparent texels are not all black. Counted from raw ROM bytes before the decoder: CI4 21775 transparent texels, 4420 with nonzero RGB (45 of 138 sprites); IA4 1175/1175 (I=7); IA8 84988/9538; IA16 853/853; RGBA16 1911/502; RGBA32 29629/5859; I4, I8, I4c, CI8: all zero. Example: Mario stock icon 296:0x72d0, 27 of 160 transparent texels carry RGB. The pack keeps ROM RGB unchanged, so RE-515's "stored black" held only for most texels.
- PPSSPP sprite-rect convention, calibrated: both rect corners are truncated to 1/16 px, a pixel is covered if its centre lies in [x0,x1), UV interpolates between the truncated corners, bilinear uses `floor((u-0.5)*32)` with 4-bit weights. It fits the Mario icon over black at 180/180 pixels within 1 level (MAE 0.02); origin-only snap 170/180, unsnapped 157/180, round-snap 145/180. Replaces RE-515's 87/117 model.
- Method (`examples/sprite_fringe.rs measure`): target is the N64 composite resampled bilinearly to PSP scale, 4 backgrounds, sub-pixel sweep, 1057 unique sprites (210M px, 64M edge px).

| Candidate | All MAE | edge MAE | Stock icons MAE | Stock edge MAE |
|---|---|---|---|---|
| Current (ROM RGB, Linear) | 1.504 | 4.47 | 3.382 | 21.32 |
| Bleed nearest (chosen) | 1.353 | 3.98 | 1.493 | 8.72 |
| Bleed mean | 1.351 | 3.97 | 1.477 | 8.61 |
| Nearest filter | 7.071 | 17.37 | 6.701 | 27.53 |
| Origin snap + bleed | 5.320 | 12.91 | 4.906 | - |
| Premultiplied (cannot ship) | 1.193 | 3.45 | 1.379 | 7.96 |

- Nearest and origin snap lose clearly (nearest wins only against a nearest-N64-pixel target, which is not what the RDP draws). Opaque FASTCOPY sprites (wallpapers) stay Linear (0.523 vs 0.822 Nearest). Damage digits and I4 emblems (white-baked) do not change.
- Choice: nearest-neighbour bleed, one ring (reads from a clone), pack time only. It adds no colours (5551 exact, CLUT small); bleed-mean ties within 0.2%.
- Residual, PSP-forced: the 1.236 scale needs a resample, so a Linear sprite cannot equal the N64's integer-pixel output; premultiplied filtering would close part of the gap but the GE cannot do it. All-sprite MAE stays 1.353.
- Goldens: 134 rows changed. A script over the difference between old and new captures found changes only within 3 px of an image gradient (one pixel of 140 in `f1-vs-mode-menu`, max delta 17, lay just outside); scenes without sprites were unchanged.

## Consequences

- Pack `VERSION` 111 (also carries RE-516's impact-wave content change that stayed at 110).
- Goldens rebaselined: the HUD, menu and sprite rows.
