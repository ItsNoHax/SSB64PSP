## Question

Where do items, the host test globals and the altitude whistle depart from the N64?

## Chansey egg flip and Metronome sweep

- `itegg.c:322`: an egg made by MLucky has `vel.x` and `lr` negated after `itEggMakeItem`. Port: `container::egg_from_mlucky`, applied in `make_setup_common_from` after the parent collision project (decomp order). GLucky path unchanged.
- Child rotate-Y 180 deg is not stored: matrix kind 46 (`objdisplay.c:902`) builds the billboard from rotate.z and scale only.
- N64 rows (seed → vel.x, lr): c823f683 → 7.7732, 1; 2d128b23 → -7.2281, -1; f59a2fc3 → -12.1035, -1. Test `chansey_eggs_turn_back_on_the_n64_draws` fails without the flip.
- Clefairy: 14 N64 rows (13 seeds 1000..16713 plus Mew 18385), 400 frames each. The trace logs the `itPippiCommonProcUpdate` word at ITStruct+0x378, which names the chosen move. All 12 Metronome entries observed. Status, lr, position, velocity and seed after selection match. Test `clefairy_selection_matches_the_n64_sweep`.
- Starmie target offset: harness artifact. Zero Fighter.coll in the harness gave vel (-18.5425, -7.4951); with both fighters `BodyColl::MARIO` and target (-1397, 904) it gives (-17.2141, 10.1821), the N64 value to 4 dp.
- Saffron/Hyrule stage monsters, weapon damage, hit order, throws: unobserved.

## Host globals per thread

- Symptom: `stage_controllers::whispys_right_wind_...` failed under load (Stop 1260/1261/1324 vs 1269).
- Cause: `game_static!` was thread-local only under ssb-game's own `cfg(test)`. Other crates' tests link ssb-game without it, so `rng::SEED`, `public::STATE`, `sound::SINK` were one process static per test binary. `rng_lock()` covered 5 tests; `packed_acid_follows_the_zebes_controller` drew without it and perturbed the replay.
- Decomp: `sSYUtilsRandomSeed` is one static (`sys/utils.c:14`); nothing in src calls `syUtilsSetRandomSeed`/`syUtilsSetRandomSeedPtr`, so the seed lives for the program. Host equivalent: one game per thread.
- Fix: `cfg(any(test, feature = "std"))` for `game_static!`, `public`, `sound`; PSP (no_std) keeps plain statics. `rng_lock()` removed. Test `host_globals.rs::another_thread_starts_its_own_game`. Before: reproducer 15/15 fail, binary 2/100; after 0/30, 0/100.

## Altitude whistle

- `stage::set_ground_kind` had no caller since 3cee04d8, so `ALT_WARNING` stayed `i16::MIN` and the whistle never played.
- Decomp: write `mpCollisionInitGroundData` (`mpcollision.c:3961`) at every battle scene start; read `ftmain.c:1817` (`pos_prev.y >= alt_warning && TopN.y < alt_warning`, not Boss) → `nSYAudioFGMAltitudeWarn`.
- Port: `battle::start_scene(gkind, damage_ratio)` = `set_ground_kind` + damage ratio + `public::make_actor`, used by `enter_training` (all battle entries). Table = ROM-generated `ground_tables::ALT_WARNING`, 41 gkinds checked.
- N64 probe (Training on Dream Land, alt_warning -2900): el 131 y -2874.3999 silent; el 132 y -2918.3999 whistles; count stays 1; after rebirth 2. Rust matches.
- Order since ported (RE-558).
- Goldens: sound only, none moved.
