# RE-509 — Fighter animation locks: frozen rest-local joints, TraRotScaInv chain, Ncs collision matrices

Status: COMPLETE for the lock semantics, bit-exact against N64 RDRAM traces (Yoshi, Samus, Mario); the slope-contour leg rewrite and the pre-display joint query log are open (see Open)
Topics: fighters, animation, rendering, reverse-engineering
Relevant files: `crates/ssb-rom/src/scene.rs`, `crates/ssb-rom/src/skeleton.rs`, `crates/ssb-rom/src/figatree.rs`, `crates/ssb-game/src/modelpart.rs`, `crates/ssb-game/src/motion/mod.rs`, `crates/ssb-tablegen/src/model_parts.rs`, `psp-runtime/src/scene.rs`, `tools/r4300/matrix_hashes.py`

## Question

What does `FTAttributes::animlock` with FTAnimDesc `is_use_animlocks` do, and does the port draw and collide the way the N64 does?

## Findings

- The flag is inverted from its name. `FTAttributes::animlock` bit n is
  descriptor n (joint n+4). FTAnimDesc bit 0x1 (`is_use_animlocks`) SET means
  the motion ANIMATES the mask joints; UNSET means they stay frozen at their
  rest local: `ftParamSetAnimLocks` stores `gmCollisionTransformMatrixAll` of
  the rest TRS (`unk_dobjtrans_0x10`, mode 3), and the display is
  `F2LFixedW` of it, once (cached by xobj `unk05` 2). The flag changes only at
  figatree install (ftmain.c:4724-4735); `ftManagerMakeFighter` sets the locks
  at creation. Every fighter has frozen joints, so every fighter on screen
  changes.
- Masks: Mario/Luigi/Fox(+N/M) 0x4a4208; DK/Captain(+N,G) 0x948208; Samus
  0x4a400408; Link 0x25200108; Yoshi 0x2520440; Kirby 0x1290420; Pikachu
  0x949010; Purin 0x948220; Ness 0x924208; Boss 0x221120. Flagged motions:
  Samus 4 (Catch, CatchPull, ThrowF, ThrowB), Yoshi 71. Masks are generated
  by `ssb-tablegen` `model_parts.rs` (D-048), not committed.
- Flagged display (`lbCommonFighterPartsFuncMatrix`, lbcommon.c:1369-1440)
  uses `lbCommonMatrixTraRotScaInv` (inv = `gLBCommonScale`, scale =
  vec_scale); the root scale is TopN's (attr size). Yoshi (1.1) shrinks about
  0.52% per flagged level (65192/65536). Collision uses the
  `gmCollisionSetMatrixNcs` chain (gmcollision.c:494).
- `transform_update_mode` 1: any part-world query
  (`gmCollisionGetFighterPartsWorldPosition`, 800EDBA4/EDE00/EDE5C, 800C9A38)
  marks the joint and its ancestors; the display then draws F2L(collision
  local). Queries after the display leave mode 1 visible in RDRAM but do not
  affect that frame. ftMainProcPhysicsMap/PlayAnim reset it next frame.
  Effect: up to 99/65536 on unflagged joints, 488 on a flagged Yoshi chain.
  Implemented as `Skeleton.locks.queried`, not yet fed (see Open).
- figatree linear key rate is a division, `(target-base) / payload`
  (ftanim.c:191), not a multiply by the reciprocal: a 1-ulp pose divergence
  found by the Samus trace.
- N64 traces (patched decomp, Mupen): Yoshi (699 frames): display words
  13020/13020 unflagged, 3906/3906 frozen, 1211/1211 flagged Inv, collision
  locals 3906/3906, Ncs worlds 44/44; end-to-end 699/699 frames, 18174 world
  rotations equal. Samus (899 frames): display unflagged 11963 + mode-1 1620,
  frozen 4794, Inv 2262; collision locals 6416/6416; Ncs 982/982; 899/899
  frames, 14485 rotations equal. Mario (399 frames, Wait + jab): frozen
  2394/2394, unflagged 6406, collision locals 3172/3172, 6112 rotations equal.
  Skipped in the end-to-end: leg chains (Mario 19/20/24/25, Samus
  27/28/32/33), which slope contour rewrites (Open).
- Trace addresses (patched build): gSCManagerBattleState 0x800a5268; FTStruct
  joints +0x8E8, status +0x24; FTParts mode +0, unk5 +5, m10 +0x10,
  mtx_translate +0x50, vec_scale +0x90; XObj unk05 +5, mtx +8. `fp+0x190` is
  not `is_use_animlocks`.
- Goldens: 159 rows differ from HEAD, all with display-frozen joints; 14 more
  rows are the earlier Yoshi/Samus/grab/jab ones. 140 rows are display-only
  sub-pixel edges on fighters (4 to 20620 px). `f1-training-pokemon-a` and
  `-b` (about 273000 px) diverge through gameplay: a motion animates a locked
  joint, the collision local becomes the rest pose and hit/hurt positions move
  (A/B with only the collision freeze disabled: 1032 and 1044 px).
