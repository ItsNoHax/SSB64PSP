# RE-363 — Zebes acid object: root writes and animated surface

Status: IMPLEMENTED (decomp, US ROM and pack tests, both PSP builds, full PPSSPPHeadless goldens, PPSSPPHeadless Zebes probe; no physical PSP)
Topics: gameplay, stages, animation, pack
Relevant files: `crates/ssb-game/src/stage/{mod,zebes,tests}.rs`, `crates/ssb-rom/src/{ground_obj,pack}.rs`, `crates/ssb-rom/tests/stage_controllers.rs`, `psp-runtime/src/scene.rs`

## Question and sources

Give the Zebes controller its acid object (`StageObj::Acid`) so the acid
draws and moves, and check which values the hazard test reads. Sources:
`src/gr/grcommon/grzebes.c` (`grZebesMakeAcid`, `grZebesAcidUpdateRise`,
`grZebesAcidCheckGetDamageKind`), `symbols/reloc_data_symbols.us.txt` and
the US ROM file 157.

## Findings

- `grZebesMakeAcid` builds `llGRZebesMapAcidDObjDesc` (`0xB08`) on display
  link 12. It attaches `llGRZebesMapAcidMObjSub` (`0x8C0`), adds
  `llGRZebesMapAcidAnimJoint` (`0xB90`) and `llGRZebesMapAcidMatAnimJoint`
  (`0xBD0`), and runs `gcPlayAnimAll` at once. Then it writes the root
  `translate.y` to the start level, −3000. The animation process runs at
  priority 5.
- The graph has two nodes: a root with no mesh and a child with the acid
  mesh at rest Y −282.725. The joint table at `0xB90` is
  `[NULL, 0xB98]`. The root has no script, so only the controller writes
  the root Y (at make and on each Rise frame).
- The child script loops the child's Y through keys −270 (frame 0), 180
  (59), −720 (120) and −270 (181) with a wait before the jump. One cycle is
  234 frames.
- `grZebesAcidCheckGetDamageKind` compares the fighter's Y with
  `dobj->translate.y + dobj->child->translate.y`. The surface therefore
  moves between −720 and 180 above the level. The RE-362 controller used
  the rest child Y (−282.725). That was a port error, not a source value.

## Implementation

- `StageObjects` gains `set_translate_y` and `child_translate`.
  `Zebes::new` plays `StageAnim::Acid` and writes the root Y. `Zebes::tick`
  reads the child Y first. The priority-5 animation has run by then, and
  the fighters' hit search comes later in the frame. A Rise frame writes
  the new root Y. With no object runtime (`NoObjects`),
  `StageInit::acid_surface_y` (the rest value) stays in use.
- `ground_obj::OBJECTS` gains `Acid` (file `0x101`, map head and graph
  `0xB08`, link 12). `ANIMS` gains slot 29, `Acid` (`0xB90`).
  `GroundObject::set_translate_y` and `child_translate` serve the port.
- Pack v45 adds the acid clip. The format does not change.
- Out of scope: the acid's `MObjSub` and `MatAnimJoint` are not played.
  The acid draws its rest material, like the other controller objects.
  Rumble (`efManagerQuakeMakeEffect`) is not ported.
