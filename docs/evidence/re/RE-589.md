# RE-589 — Tables read from the pack: frame cost of the run-time sine tables (ROM-free release)

Status: MEASURED (PSP-2000 hardware)
Topics: performance, hardware, rom-free
Relevant files: `crates/ssb-tables/src/lib.rs`, `crates/ssb-tablegen/src/tables.rs`, `crates/ssb-engine/src/math.rs`, `psp-runtime/src/tables.rs`

## Findings

1. `ssb-engine`'s two sine tables (`SinTable` u16 x 2048, `LbCommonSinLookup` f32 x 1024) moved from `include!`d `OUT_DIR` constants to the pack's `TABLES` section ([D-048](../../decisions/D-048.md)). Callers in `math.rs` read them on gameplay and render paths.
2. Designs measured on the PSP-2000 (6.61 ARK, PSPLink, ms0 pack, scenes vs4 / 1P intro and battle / Zebes / Electric `vs4@2170`; deltas against HEAD ad719671 in the same session):

| Design | Link | Delta (ms) |
|---|---|---|
| Lazy: `Table::get` checks a ready flag, zero table until installed | unpinned | +0.22 to +0.61 |
| Eager pointer: `install` stores one pointer, `get` reads it unchecked | unpinned | -0.18 to +0.13 (parity) |
| Eager pointer | pinned (`link-pins.txt`) | +0.09 (Zebes) to +0.24 (battle, r14); r12 16.39 to 16.60 |
| Eager store: fixed `.bss` store, `install` copies each table to a constant offset | pinned | -0.02 (intro) to +0.17 (battle); vs4 +0.13, Zebes +0.07, r12 / r18 / r14 +0.16 (r12 16.55) |

   - Two rounds, alternating order; per-round spread 0.01 ms or less.
   - Pinned link: functions moved off their pins: HEAD 14, eager pointer 46, eager store 32. Sine-table callers (`hand_transform`, `transform_matrix`, `leg_ik`, `update_struct`, `release_with`) grow 4-68 bytes.
   - Likely cause: the tables are no longer constant to LLVM, so their loads are not hoisted or merged across stores.
3. Kept: eager store. Cost +0.16 ms on Electric r12 (16.55, under 16.7). PSP builds use feature `eager`; host builds keep the checked lazy path.
