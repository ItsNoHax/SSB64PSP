# RE-525 — Opening movie fighter scenes: effects use the movie camera, billboards follow it, and a two-cycle combiner can still carry texel-times-prim alpha

Status: COMPLETE on host and PPSSPP; physical PSP not re-run
Topics: opening movie, particles, billboards, display effects, Samus Grapple Beam glow, Yoshi's Island cloud alpha
Relevant files: `psp-game/src/main.rs`, `psp-runtime/src/gu.rs`, `psp-runtime/src/scene.rs`, `crates/ssb-game/src/grab.rs`, `crates/ssb-rom/src/mesh.rs`

## Question

Why did the opening's fighter scenes differ from the N64 in dust, impact waves, Samus's beam tip, tree and cloud billboards, and Yoshi's Island clouds?

## Findings

- **Particles.** `lbParticleDrawTextures` projects through the camera that is current, so under the movie camera it uses the movie's roll, projection, planes and viewport. The port projected through the battle look-at.
- **Display effects start changed.** `efManagerMakeEffect` uses `gcAddAnimAll`, which sets `AOBJ_ANIM_CHANGED`; the make's `gcPlayAnimAll` then parses frame 0 without advancing. N64 RDRAM at the Donkey Kong scene's tic 41 shows the Impact Wave at `anim_frame` 7 after 8 plays. The port advanced once more, so these effects ran one frame ahead (display effects, Thunder Shock).
- **Samus Grapple Beam glow.** `efManagerSamusGrappleBeamGlowMakeEffect` is made in Catch and Throw; its clock is held during hitlag. Its kind-46 child is a billboard spun by `rotate.z`.
- **Billboards.** Kind 46 takes the rolled view's right and up. Kind 48 takes the camera-mode-3 `sGCMatrixMod1F` basis: right is the view's right, up is `d/n*up - dy/n*back`, scale zero when `d < 1e-4`.
- **Yoshi's Island clouds.** `llGRYosterMapCloudDisplayList` (file 154 +0x580) is two-cycle: `G_SETCOMBINE FC309604 5FFEFFF8`, `G_RM_AA_ZB_XLU_SURF2`. Cycle 0 alpha is `TEXEL0*PRIM`; cycle 1 passes `COMBINED` through. A classifier that rejects every two-cycle combiner drops the fade and draws the cloud opaque. It now accepts cycle 1 of `(A-B)*0 + COMBINED_ALPHA` (pack v116).

## Verification

Host unit test for the classifier (fails if cycle 1's C or D slot is broken). Region MAE against N64 frames fell in every scene (Donkey Kong tic 41: 19.5 to 11.0). Goldens `f1-opening-donkey-impact`, `f1-opening-samus-grapple`, `f1-opening-yoshi-cloud` pin the effects.

## Open

Battle (non-movie) kind-46 and kind-48 bases are still the identity. `EffectVisuals` still uses `anim.start` and may carry the same off-by-one; unverified.
