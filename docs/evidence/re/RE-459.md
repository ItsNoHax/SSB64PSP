## Save data boundary

The scenes need only the in-memory `gSCManagerBackupData` fields the port
already keeps (`Backup`): the unlock and fighter masks, records and
`characters_fkind`. `lbBackupWrite` is counted in `Backup::writes`; nothing is
persisted to the memory stick, so unlocks last for the session only. The
selects read the same masks, so an unlocked newcomer is selectable until the
game exits.

## PSP deviations

- The staff roll's 640 x 480 picture (`dSCStaffrollVideoSetup`) is drawn on
  the usual pillarboxed 320 x 240 grid: 2D positions halved, sprites at half
  size.
- The background's material animation (played once at frame 0) is not
  applied; its materials draw as packed.
- The congratulations pictures are 24-bit (no texel is 5-bit exact), so they
  stay 8888, each cut at column 256 to pad to 256 + 64 texels rather than
  512. The collage is CI4 through an RGBA16 palette and packs as 5551.
- No audio (BGM, announcer, door and selection sounds).

## Memory
