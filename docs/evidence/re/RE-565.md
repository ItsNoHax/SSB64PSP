## Fixes

- DK cargo knee-bend, fall, landing: `StatusTiming::held()`.
- Barrel at speed 0 (`Status::TaruCann => 0.0`); Barrel and Twister setters drop a heavy item.
- Guard `anim_frame` mirrors `angle_f`; the drawn pose still reads `clock`.
- `wpmap::apply_gravity_clamp_tvel` = `wpMainApplyGravityClampTVel` = `itMainApplyGravityClampTVel`.

## Item-throw gravity clamp (1/mag)

- `itMainApplyGravityClampTVel` computes `lbCommonNormDist2D`, multiplies by `1/mag`, then by `tvel`. The port divided (`x / mag * tvel`).
- Effect: 1 ulp on a thrown Beam Sword; vx -99.17158 vs N64 -99.17157 (bits `c2c657d8`, `itm4.txt`); position drifted past print precision by t=216.
- Tests: `item/heavy_tests.rs` `terminal_velocity_clamp_multiplies_by_the_reciprocal`; `castle_replays.rs` `link_smash_throws_beam_swords_back_and_up_as_on_the_n64`.

## Fireball 2D speed clamp

- `wpMarioFireballProcUpdate` calls `wpMainApplyGravityClampTVel`: both axes clamp to speed 55. The port clamped `vy` at -55 only.
- Trace `b30set/fb1.txt` (`re473/warp/warp_mario.z64`, `100:2:x=-128;130:1:b`): from t=231 x speed falls -30.343, -28.388 ... -10.741 at t=281.
- Test: `castle_replays.rs` `a_falling_fireball_clamps_its_speed_as_on_the_n64`.
- Goldens: `f1-cpufx-jolt` 379 native px (1516 of 960x544), `f1-cpufx-jolt-end` 489 native px (1956). Gameplay change, not renderer (D-051).

## Harness additions and deviations

- `common/posed.rs` `HostArena::tick_stage`: runs `Stage::tick` with the replay's map (no line groups, no props).
- Twister replay: stage from the pack's Hyrule `stage_points`/`hazard_descs`; seed 1 before tick 1; one stage tick pre-rolled before tick 1 (N64 frame 0 already ran the Ground processes).
- RNG seed injection: `0xA51FB561` at tick 1680. The N64 Summon particle scripts draw RNG; the host runs no particles. Value = N64 frame-1679 seed `0xFF619947` stepped 10 times.

- N64: `gGRCommonStruct` US 0x801313F0 (the local build map's 0x80131570 is wrong for the US ROM).
